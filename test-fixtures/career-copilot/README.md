# 智能求职助手纯虚构测试样本集

本目录只存放为自动化测试人工编写的纯虚构材料，不对应任何真实个人、学校、公司或招聘岗位。

## 内容

- `resumes/`：10 份简历文本样本；
- `jds/`：6 份 JD 文本样本；
- `manifest.json`：场景、语言和预期解析结果的唯一清单。

当前覆盖空白输入、双相关实习、商科缺少量化、跨专业、低年级经历少、时间重叠/倒序/缺失、中文、英文、中英混合、联系方式密集、表格式排版、无标题内容、高匹配 JD、低匹配 JD 和风险招聘措辞。

## 使用规则

1. 禁止把真实用户简历、真实求职者信息或内部咨询材料复制到本目录。
2. 新增非空样本首行必须是 `# SYNTHETIC FIXTURE — NOT A REAL PERSON OR JOB`。
3. 学校、组织和岗位必须明确为虚构；需要测试联系方式时只使用保留测试域名或明显不可拨通号码。
4. 新增样本必须同时登记到 `manifest.json`，写明场景和可验证预期。
5. 运行 `pnpm run validate:fixtures`；生产构建也会自动执行同一门禁。
6. 若需要真实格式边界文件，如扫描 PDF、加密 PDF、损坏 DOCX 或超限文件，应使用程序生成的无个人信息二进制，并在对应任务中单独登记，不得从真实简历改造。

样本仅用于质量验证，不会打包进网站生产静态资源。
