## 2. 时间线观察

### 0-3 秒

画面从暗场进入，中心出现产品页面预览。背景是被压暗和虚化的素材墙。主体被暖色边缘光包围，有明显的舞台感。

### 3-8 秒

中心画面切换为深色产品页，再快速穿插白色页面。黑白场景交替带来节奏变化，避免全程暗色沉闷。

### 8-16 秒

继续展示深色产品页，画面推近。主体内容的 UI 截图保持矩形边界，外围用 blur、shadow、glow 做空间层次。

### 16-24 秒

出现球体、曲面、光环等更具宏观感的视觉元素，强调“系统能力”“全球/未来/计算”的感觉。

### 24-31 秒

回到清晰的产品页面和价格/方案展示，结尾更接近转化页。节奏从叙事展示落到具体信息。

## 3. 可借鉴部分

- 用单一中心舞台承载所有主要内容。
- 用背景素材墙制造“品牌内容很多、体系很完整”的暗示。
- 用暖色边缘光让暗色页面不死黑。
- 用慢速镜头和景深提升高级感。
- 页面切换要有“场景切换感”，而不是普通网页滚动。
- 关键内容可以像幻灯片或产品演示一样分幕展示。

## 4. 不建议直接照搬

- 不直接复制 AI 产品的橙黑科技 UI。
- 不使用过多飞线、粒子和浮动图标。
- 不让页面像模板宣传视频截帧。
- 不用高频切换干扰用户阅读服务信息。

## 5. MoreThan 转译方案

对标视频的“AI 产品演示片”应转译为 MoreThan 的“求职决策系统”：

- 中心舞台：当前页面核心内容
- 背景素材墙：offer 案例、服务模块、岗位标签、导师领域
- 暖橙边缘光：机会、结果、关键节点
- 黑场：专业、克制、可信赖
- 白场穿插：简历优化、案例档案、清晰诊断
- 镜头推进：从品牌愿景进入具体服务，再进入联系转化
