# MoreThan 求职品牌网站最终参考文档

版本：v1.0
更新时间：2026-08-08
状态：Phase 8 已完成，基础动效版本冻结，等待用户验收

## 1. 已确认方向

用户已确认：

- 认可“中心舞台 + 背景案例墙 + 暖橙边缘光 + 页面级转场”的动效方向。
- 认可“先用 CSS/React 实现，后续必要时再引入 Framer Motion”的技术路线。
- 整体气质偏向“高级咨询机构官网”，不是强产品宣传片。

用户新增核心要求：

- 增加图片，用图像替代大段文字表述。
- 少用文字，文案要精简、准确、克制。
- 多用分屏结构，适合分屏的内容必须分屏。
- 求职陪跑服务流程必须重点做成分屏叙事。
- 实现“往下滑一页，就出现一部分图 + 精简文字介绍”的体验。
- 全站必须有高级感。

## 2. 项目目标

为 MoreThan 求职品牌主页建立一套正式、宏大、可持续迭代的视觉与动效系统。

这不是简单给现有页面加动画，而是重构为更接近高端咨询机构官网的体验：

- 一屏一个主题。
- 图像先行，文字辅助。
- 分屏叙事承载服务流程。
- 动效服务于信任感、专业感、结果感。

## 3. 信息架构原则

原先的纯分页按钮切换，需要升级为“分页导航 + 滚动分屏”的混合结构。

建议结构：

- 首页 Hero：品牌第一印象。
- 服务介绍：用多屏分屏讲清服务矩阵。
- 求职陪跑流程：重点分屏模块，每滑一屏展示一个阶段。
- 学员反馈：用案例图像/档案式视觉替代长段落。
- 加入社群：用信息流、机会流、二维码视觉化表达。
- 关于我们：团队规模、成员、愿景，用数据和人物图像表达。
- 联系我们：高亮二维码与极简收益点。

导航规则：

- 左上 Logo 点击回到首页。
- 右上“联系我们”跳转联系方式。
- 中部导航可以跳转到对应大章节。
- 页面内部采用滚动吸附或接近滚动吸附的“一屏一主题”体验。

## 4. 对标视频转译

参考视频的核心不是颜色，而是镜头语言：

- 中心舞台式展示。
- 背景素材墙制造规模感。
- 主体清晰，背景虚化。
- 暖橙边缘光强调焦点。
- 页面像一幕一幕被揭示。

MoreThan 的转译方式：

- “产品页面”转译为“求职方案、案例档案、服务流程”。
- “AI 科技感”转译为“决策系统感、专业流程感”。
- “宣传片节奏”转译为“高级咨询机构的沉稳叙事”。

## 5. 视觉内容策略

图片优先级高于文字。

可使用的图片类型：

- 抽象求职路径图。
- 服务流程图。
- 案例档案卡。
- offer 结果墙。
- 导师团队头像或剪影。
- 简历优化前后对比视觉。
- 面试模拟场景视觉。
- 社群信息流视觉。

文字策略：

- 每屏主标题控制在 8-16 个汉字。
- 每屏说明控制在 1-2 句。
- 尽量使用短标签、数字、流程节点替代段落。
- 删除重复解释性文案。

## 6. 分屏规范

基础分屏：

- 左图右文，或左文右图。
- 每屏高度接近 100vh。
- 文字区域宽度不超过 520px。
- 图像区域占 52%-62% 横向空间。

适合分屏的模块：

- 求职陪跑流程。
- 简历优化。
- 面试模拟。
- 案例反馈。
- 团队介绍。

求职陪跑流程建议拆成 6 屏：

1. 诊断：识别背景、短板、目标。
2. 定位：确定主投方向、备选方向、企业层级。
3. 强化：简历、项目、背景提升。
4. 投递：节奏规划、内推、进度管理。
5. 面试：模拟、复盘、表达训练。
6. 决策：offer 比较、谈薪、签约建议。

## 7. 动效规范

全局：

- 滚动进入一屏时，图像先进入，文字后进入。
- 图片可以有轻微推近、裁切显现、边缘光。
- 文案只做轻微上浮和透明度变化。
- 不使用过多弹跳、旋转、飞入。

时间：

- 屏幕入场：700-900ms
- 图片显现：800-1100ms
- 文案显现：500-700ms
- Hover：160-220ms
- 背景漂移：20-40s

缓动：

- 主转场：cubic-bezier(.16, 1, .3, 1)
- Hover：cubic-bezier(.2, .8, .2, 1)

## 8. 技术策略

当前阶段：

- React + Vite。
- CSS scroll snap 或 IntersectionObserver。
- CSS variables 管理动效 token。
- CSS keyframes 处理背景和局部动效。

暂不引入 Framer Motion，除非后续需要：

- 复杂页面离场动画。
- shared layout。
- 3D 层叠式转场。

## 9. 验收原则

每完成一个任务必须用户确认。

验收标准：

- 是否更像高级咨询机构官网。
- 是否显著减少文字。
- 是否用图片承担主要表达。
- 是否形成“一屏一个主题”的节奏。
- 服务流程是否分屏且清晰。
- 是否高级、克制、有科技感。
- 是否没有模板网站感。

## 17. Phase 8 验收与版本冻结

本轮完成全站基础版本验收：

- 动效触发从“页面加载时统一播放”修正为“每屏进入视口后播放一次”。
- 统一图像 920ms、文案 780ms、文案延迟 140ms 的先图后文节奏。
- 保留 `prefers-reduced-motion`，系统选择减少动态效果时关闭滚动吸附与长动画。
- 在 1280px PC 视口完成逐屏检查，修复团队网络、案例背景造成的横向溢出。
- 补齐 HTML 语言、视口、主题色、页面标题和搜索描述。
- 文案继续遵循“短标题 + 一句说明 + 三个短标签”，未增加解释性长段落。
- 服务流程、案例、社群、团队和联系页均以图形装置承担主要表达。

基础动效版本 v1.0 至此冻结。真实图片、品牌视频、案例截图、人物头像和二维码不属于本轮基础版本阻塞项，继续统一记录在 `05_ASSET_TODO.md`，后续作为独立资产专项执行。
