# MoreThan 品牌主页需求文档

版本：v0.2
更新时间：2026-08-04

## 1. 项目定位

MoreThan 求职品牌主页需要呈现为一个高级、克制、专业的咨询机构官网。它的重点不是堆服务文字，而是用视觉、分屏和动效让用户快速理解：

- MoreThan 是专业的求职陪跑团队。
- 服务流程完整且可执行。
- 案例真实，有结果支撑。
- 用户可以通过社群或微信进入下一步。

## 2. 核心需求

### R-01 图片替代文字

要求：

- 每个核心模块必须有主要视觉图像或图形。
- 不允许大段文字解释服务。
- 服务、流程、案例优先使用图像、标签、数字、结构图表达。

验收：

- 首屏以下每个大模块都有图像承载。
- 页面整体不是文字型官网。

### R-02 少文字

要求：

- 每屏只保留一个主标题。
- 每屏最多 1-2 句说明。
- 次级信息用标签、数据、图标表达。

验收：

- 任意一屏都能在 3 秒内读完主信息。

### R-03 滚动分屏

要求：

- 页面采用向下滚动的分屏结构。
- 滚动一页，出现一组“图 + 精简文字介绍”。
- 适合分屏的内容必须分屏。

验收：

- 首页后至少有多个接近 100vh 的分屏 section。
- 滚动体验有明确段落感。
- PC 端阅读节奏清晰。

### R-04 求职陪跑流程分屏

要求：

求职陪跑服务流程必须作为重点模块分屏展示。

建议阶段：

1. 诊断
2. 定位
3. 强化
4. 投递
5. 面试
6. 决策

验收：

- 每个流程阶段独立成屏或半屏重点区域。
- 每个阶段有图像/图形，而不是纯文字。

### R-05 高级感

要求：

- 暗色基底。
- 克制动效。
- 边缘光、景深、图像层次。
- 不使用模板站式大段卡片堆叠。

验收：

- 页面视觉更接近高级咨询机构官网，而不是课程销售页。

## 3. 功能需求

### FR-01 导航

- Logo 点击回首页。
- 右上“联系我们”跳转联系方式。
- 中部导航跳转到主要章节。

### FR-02 滚动章节

- 支持鼠标滚轮向下浏览。
- 每个 section 有稳定的屏幕空间。
- 可采用 CSS scroll snap，但如果体验过硬，也可使用接近吸附的自然滚动。

### FR-03 入场动效

- section 进入视口时触发图文入场。
- 图片先出现，文字后出现。
- 动效必须克制。

### FR-04 图片资产

第一版可用抽象图形、CSS 生成视觉、案例档案式 mockup 作为占位。

后续用户提供真实截图、二维码、照片后替换。

## 4. 非功能需求

性能：

- 首屏不卡顿。
- 背景动效不影响交互。

兼容：

- PC 优先。
- 版心约 1700px。
- 支持 Chrome / Edge。

可访问性：

- 支持 `prefers-reduced-motion`。
- 导航按钮可键盘访问。
- 动效不影响内容理解。

## 5. 暂不做

- 移动端完整设计。
- 后台 CMS。
- 真实二维码替换。
- 真实团队照片生成。
- 部署上线。
