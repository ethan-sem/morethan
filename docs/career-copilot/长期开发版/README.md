## 1. 版本定位

长期开发版承接需要服务端能力的完整产品方向，包括账号、云端历史报告、服务端 AI、数据库、实时/准实时招聘数据、运营后台、评测平台和商业化。它不属于当前纯前端 MVP 的开发范围。

## 2. 冻结模块

- 注册、登录、身份验证、用户中心和多设备同步；
- API 网关、应用服务、任务队列、数据库和对象存储；
- 服务端模型调用、提示词编排、异步报告任务和模型成本控制；
- 云端简历、报告历史、删除/导出和数据生命周期；
- 外部职位数据自动接入、定时更新、去重和时效治理；
- 顾问/运营后台、审核流、规则管理和知识发布；
- 监控、审计、权限体系、灰度、容灾和正式合规评估；
- 付费、订阅、订单以及长期商业化功能。

## 3. 未来启用流程

当用户明确要求启用长期版时，Codex 应：

1. 重新确认目标用户、流量、预算、数据保存策略和上线区域；
2. 以当时的法律、招聘数据授权、模型 API 和基础设施现状重新调研，不直接照搬旧结论；
3. 决定账号是否必要，以及采用托管身份服务还是自建；
4. 将 MVP 已验证的解析、规则、报告和知识 Schema 作为迁移输入；
5. 新建长期版的生效任务清单，逐步替代冻结的历史任务库；
6. 在用户确认迁移计划前，不破坏仍在线的纯前端 MVP。

## 4. 当前禁止事项

“长期愿景中存在”不等于“当前已授权”。在版本冻结期间，不得因某个 MVP 任务顺带创建账号表、部署 API、接入云数据库、保存用户简历或嵌入品牌 API 密钥。
