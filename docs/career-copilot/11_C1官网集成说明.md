> 版本归属：MVP 与长期版共享的历史实施记录

> 完成日期：2026-08-09

## 1. 现有架构盘点

现有 MoreThan 官网采用：

- React + Vite；
- `src/main.jsx` 作为主应用入口；
- URL Hash 作为轻量页面路由；
- `main[data-page]` 与 `.page-*` 控制页面显示；
- 全局 `src/styles.css` 管理品牌官网样式；
- `lucide-react` 作为图标系统；
- 首页、服务详情、案例、社群、游戏、团队和联系页共享同一 React 根节点。

该结构足以承载 Phase C1，无需为了智能助手提前更换路由框架或重构整站。

## 2. 集成决策

### 路由

- 智能助手使用 `#career-copilot`；
- 作为官网主导航的一级入口“智能求职助手”；
- 继续使用现有 `navigate()` 与 `hashchange` 机制；
- 后续若改为正式服务端路由，可在不改变组件内部流程的情况下迁移。

### 代码边界

- `src/main.jsx`：只负责入口、路由和站点级挂载；
- `src/careerCopilot.jsx`：负责助手流程、状态和页面骨架；
- `src/career-copilot.css`：负责助手独立 token、组件和响应式样式；
- 不把智能助手的复杂状态继续堆入原有主页组件。

### 状态

Phase C1 使用会话级 `sessionStorage` 保存：

- 当前流程步骤；
- 已访问步骤；
- 本地选择的文件名称。

它只用于页面骨架和刷新恢复，不读取或持久保存简历内容。Phase C2 建立后端后，再把业务状态迁移到正式会话与数据库。

## 5. 关键交互规则

- 用户只能返回已访问的流程步骤；
- 页面刷新后恢复本次会话位置；
- 文件选择阶段只记录文件名，不读取文件；
- 示例报告可从首页直接查看；
- 事实纠错可回到事实确认页；
- 数据设置可重置本次会话；
- 所有主操作具备键盘焦点；
- 移动端智能助手隐藏不适配的全站桌面导航，保留助手自己的返回入口。

## 6. Phase C1 不包含

- 真实文件上传和解析；
- 用户账号和后端保存；
- 模型调用；
- 外部岗位数据；
- 真实报告生成；
- PDF 导出；
- 顾问后台。

在当前纯前端 MVP 路线中，文件解析、规则分析、静态知识数据和报告导出由 MVP 任务承接；账号、后端、云端模型调用、实时外部数据和运营后台均冻结到长期开发版。
