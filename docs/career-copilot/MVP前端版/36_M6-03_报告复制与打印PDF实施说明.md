# M6-03 报告复制与打印 PDF 实施说明

## 1. 完成范围

M6-03 为真实诊断报告增加两种本地导出方式：

1. 复制脱敏文本；
2. 调用浏览器打印，并由用户选择打印机或“保存为 PDF”。

本任务不引入服务端 PDF 服务，也不上传报告内容。

## 2. 脱敏文本

纯文本生成器只接收结构化分析结果，不接收原始简历正文、敏感字段或文件对象。输出包括：

- 生成时间、规则版本、岗位画像版本和公司知识包版本；
- 30 秒结论；
- 最多三项优势与三项短板；
- JD 差距或“未提供 JD”说明；
- 四层投递组合；
- 带官方入口、来源和核验日期的公司目标池；
- 48 小时、7 天、30 天行动；
- 使用边界、信息时效和非录用保证。

文本明确说明不包含姓名、联系方式、完整简历原文或原始文件信息。复制失败时只提示剪贴板权限问题，不回退为包含敏感内容的 DOM 选择复制。

## 3. 打印与 PDF

“打印 / 保存 PDF”调用浏览器原生打印功能。专用 A4 打印样式：

- 隐藏官网导航、流程进度、导出工具和操作按钮；
- 增加 MoreThan 报告页眉与使用边界页脚；
- 保留摘要、方向、优势短板、JD、四层建议、公司池、行动和免责声明；
- 调整深色卡片为适合纸张的浅色版本；
- 关键卡片避免跨页断裂；
- 公司与岗位来源链接继续以可识别文字展示；
- 默认收起的交互证据详情不进入打印，避免报告异常膨胀；用户主动展开的详情可随页面打印。

## 4. 产品与隐私边界

- 不自动下载文件，避免浏览器拦截和不可控文件写入；
- PDF 是否生成、保存位置和文件名由浏览器及用户决定；
- 不将复制或打印内容写入浏览器存储；
- 示例报告不提供个性化导出能力；
- 打印功能受独立功能开关控制，复制脱敏文本保持可用；
- 用户保存到本地的 PDF 属于用户自行管理的文件，后续“一键清除”无法删除该文件。

## 5. 验收要点

- 真实报告顶部出现复制和打印入口；
- 复制文本覆盖完整报告结构并保留必要免责声明；
- 复制文本不包含原始简历全文、姓名或联系方式；
- 复制成功和失败都有无障碍状态反馈；
- 打印按钮调用浏览器原生打印窗口；
- 打印版不显示导航、按钮和交互工具；
- A4 打印样式保留报告标题、来源、时效信息和非录用保证。
