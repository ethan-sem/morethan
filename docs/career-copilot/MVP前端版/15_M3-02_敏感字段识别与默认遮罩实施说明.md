# M3-02 敏感字段识别与默认遮罩实施说明

> 完成日期：2026-08-10  
> 状态：已完成  
> 识别器版本：`1.0.0`

## 1. 目标与结果

M3-02 在不增加账号、后端、数据库或网络请求的前提下，实现简历敏感字段的浏览器本地识别和默认遮罩。

PDF、DOCX、TXT、直接粘贴和手工填写在完成文本解析后，都会生成 `ResumeFacts.privateFields` 兼容记录。当前材料页的文本预览已默认遮罩；后续 M6 报告、复制和打印必须复用同一遮罩函数。

## 2. 已覆盖字段

| 类型 | 识别边界 | 默认遮罩示例 | 置信度 |
|---|---|---|---|
| 姓名 | `姓名/Name` 标签；或简历页眉且附近有电话/邮箱 | `张**`、`A***` | 标签高、页眉中 |
| 手机 | 中国大陆 11 位手机号，可含 `+86`、空格或连字符 | `138****5678` | 高 |
| 固定电话 | 以 `0` 开头的区号和 7/8 位号码 | `010-****5678` | 高 |
| 邮箱 | 常见本地部分和多级域名 | `z***@example.com` | 高 |
| 详细地址 | 显式地址标签且包含省市区、道路、门牌等详细信号 | `[详细地址已隐藏]` | 高 |
| 身份证号 | 15 位历史格式或通过日期和校验位的 18 位号码 | `110***********002X` | 高 |

身份证号属于“等敏感字段”的安全扩展，类型已经由 `ResumeFacts 1.0.0` 预留。

## 3. 保守识别原则

姓名和地址容易误识别，因此不采用宽泛的“像姓名/像地点”推断：

- 无标签姓名必须位于前四个非空行，并且前 320 个字符内存在电话或邮箱；
- “个人简历”“教育经历”等标题不会被识别为姓名；
- 地址必须有显式标签并包含至少两个地址信号，或包含道路与门牌组合；
- “目标城市：上海”、毕业年份、普通项目指标和无效身份证样式不会被遮罩；
- 同一区间命中多种规则时只保留优先级最高的一项，避免重复替换和区间错位。

规则识别不能保证覆盖所有非标准写法。M3-04 将提供用户确认、误识别撤销及手工补充入口。

## 4. 数据与隐私边界

识别结果只包含：

- 确定性 ID；
- `name / phone / email / address / id_number` 类型；
- 遮罩值；
- 文档 ID 和 UTF-16 起止区间；
- 置信度；
- `detected / confirmed / dismissed` 状态。

结果不包含 `rawValue`、原文摘录、文件名或原始文件。原值只在一次函数调用的局部变量和页面内存中的解析正文里短暂存在，不写入 `ResumeFacts`、localStorage、sessionStorage、URL、日志或网络请求。

遮罩函数只使用来源区间和遮罩值：`detected`、`confirmed` 会遮罩，`dismissed` 不遮罩；越界区间和其他文档的区间会被忽略。

## 5. 页面接入

解析成功后，页面为当次材料生成不包含个人信息的顺序文档 ID，并把敏感字段记录附加到内存解析结果。预览渲染时即时应用遮罩，并展示“X 项敏感信息已默认遮罩”。

输入 textarea 仍允许用户查看和编辑自己刚刚输入的原文；材料预览及未来分析/报告展示使用遮罩路径。清除本次流程或刷新页面后，正文和识别结果都会消失。

## 7. 已知边界

- 不做 OCR，图片中的联系方式仍不可识别；
- 非中国大陆电话号码仅在符合当前固定电话规则时覆盖；
- 无标签且缺少地址信号的详细住址可能漏识别；
- 当前未提供用户确认界面，该交互归 M3-04；
- 当前未生成正式诊断报告，M6 接入报告输出时必须再次验证默认脱敏。
