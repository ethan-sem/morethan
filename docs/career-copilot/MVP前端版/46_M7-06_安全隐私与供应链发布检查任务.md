# M7-06 安全、隐私与供应链发布检查任务

> 文档状态：已完成  
> 任务状态：`[done]`（2026-08-20）  
> 适用版本：MoreThan 智能求职助手 MVP 前端版  
> 部署形态：纯前端静态站点，无账号、无业务后端、无数据库  
> 核心原则：默认不联网处理简历、最小权限、关闭式白名单、构建产物可审计
> 实施记录：`50_M7-06_安全隐私与供应链发布检查实施记录.md`

## 1. 任务目标

在发布前对智能求职助手执行一次覆盖源码、依赖、构建产物、浏览器运行时和静态托管配置的安全检查，确保：

1. 网站源码和构建产物中不存在 MoreThan 或用户的 API 密钥；
2. 简历、JD、事实、报告和临时密钥不会被发送到网络或写入持久化存储；
3. 用户上传的 PDF、DOCX、TXT 只作为不可信本地输入处理，不执行其中的脚本、宏、HTML 或外部对象；
4. 页面具备适合纯静态产品的 CSP 和安全响应头；
5. 第三方依赖、锁文件和构建链不存在未处置的高危风险；
6. 错误、日志、页面提示、剪贴板和打印结果不会泄露敏感原文；
7. 新增外部数据或功能时只能通过明确白名单扩展安全边界。

本任务不承诺“绝对安全”，也不替代专业渗透测试；其目标是关闭当前 MVP 发布前可识别、可验证的 P0/P1 风险。

## 2. 当前安全基线

### 2.1 已有能力

- 已有构建前隐私扫描，禁止求职助手源码直接调用 `fetch`、XHR、WebSocket、EventSource 和 `sendBeacon`；
- 只有流程导航状态可以通过白名单模块写入 `sessionStorage`；
- 禁止把简历、JD、分析、报告或密钥直接序列化为持久状态；
- 禁止密钥写入日志、DOM 明文或不安全自动填充；
- 原始简历、提取文本和报告默认只驻留当前页面内存；
- PDF、DOCX、TXT 和事实提取已放入独立 Worker；
- BYOK 实验功能默认关闭，示例环境文件明确禁止填写 API 密钥；
- 文件格式、大小、加密、损坏和空文本已有前置校验；
- PDF 脚本执行、DOCX HTML 渲染、宏和嵌入对象不属于处理链路。

### 2.2 当前缺口

- 隐私门禁主要扫描求职助手源码，尚未覆盖全部生产构建产物；
- 尚未建立通用秘密值、高熵字符串和 source map 泄露检查；
- 尚未配置并实测部署层 CSP、Permissions Policy、Referrer Policy 等安全响应头；
- 尚未建立生产依赖漏洞、版本锁定和许可证变更门禁；
- M7-05 引入静态知识数据按需读取后，需要从“完全禁止网络”升级为精确的同源公开数据白名单；
- 尚未形成浏览器运行时请求清单、控制台脱敏和外链跳转的统一发布证据。

## 3. 保护对象与信任边界

### 3.1 保护对象

- 用户上传的原始简历文件；
- 解析得到的简历正文和敏感字段；
- 用户确认的 `ResumeFacts`；
- 用户粘贴的 JD 与差距分析；
- 职业画像、报告和行动计划；
- 用户主动输入的临时 BYOK 密钥；
- 内部顾问维护的公司岗位数据与发布记录；
- MoreThan 品牌域名、静态发布产物和依赖供应链。

### 3.2 信任边界

| 边界 | 默认信任 | 安全要求 |
|---|---|---|
| 用户文件 → 浏览器 | 不信任 | 校验后在 Worker 纯文本提取，不执行内容 |
| Worker → 页面状态 | 有限信任 | 只接受关闭式结构和安全错误码 |
| 页面内存 → 浏览器存储 | 默认禁止 | 仅允许无敏感内容的流程位置 |
| 页面 → 网络 | 默认禁止 | 仅允许同源静态资源和审核过的公开知识数据 |
| 页面 → 外部招聘网站 | 不传数据 | 只做用户主动点击的普通 HTTPS 导航 |
| 环境变量 → 前端构建 | 不信任秘密值 | `VITE_` 变量全部视为公开内容，不得放密钥 |
| 第三方依赖 → 构建产物 | 有限信任 | 精确锁版、完整性校验、漏洞和许可证检查 |

## 4. 密钥与配置安全

### 4.1 禁止内容

- MoreThan 自有模型、云服务、数据库、邮件或分析平台密钥；
- 用户 BYOK 密钥的默认值、示例真值、日志、错误回显或持久化副本；
- 私钥、证书私钥、访问令牌、Webhook secret、数据库连接串；
- 含真实凭据的 `.env`、调试文件、构建日志、截图或测试夹具；
- 通过 Base64、字符串拆分或运行时拼接隐藏的秘密值。

### 4.2 扫描范围

必须扫描：

- `src/`、`public/`、`scripts/`、配置文件和文档示例；
- `.env.example` 以及被版本控制的其他环境模板；
- Vite 生产构建后的 HTML、JS、CSS、JSON、Worker 和 source map；
- 发布压缩包或实际准备上传的目录；
- Git 已跟踪文件中的常见密钥模式和异常高熵字符串。

测试使用的虚构密钥必须满足统一假值格式，并进入精确允许列表；不得使用宽泛正则忽略整个测试目录。

### 4.3 环境变量规则

- 所有 `VITE_` 变量都按“最终会公开给浏览器”处理；
- 只能存放布尔功能开关、公开版本号和非敏感静态配置；
- `.env.example` 只包含空值或明确的公开示例；
- 本地 `.env` 不进入版本控制和发布目录；
- BYOK 保持用户运行时主动输入、仅内存保存，默认构建开关继续关闭。

## 5. 网络与数据外发控制

### 5.1 默认网络策略

允许：

- 同源 HTML、脚本、样式、字体、图片和 Worker；
- M7-05 确认后的同源、只读、公开公司岗位 JSON；
- 用户主动点击并在新页面打开的 HTTPS 官方招聘入口。

禁止：

- 把简历文件、正文、哈希、文件名、JD、事实、画像、报告或密钥发送到任何域名；
- 分析、埋点、广告、错误监控、远程日志或会话回放自动采集求职助手页面内容；
- 以查询参数、URL hash、请求头、Referer 或静态数据请求路径编码用户材料；
- WebSocket、EventSource、Beacon、表单提交和隐藏图片像素外发；
- 外部 CDN 在运行时加载解析器、字体、脚本或模型文件；
- Service Worker、Cache Storage 或 IndexedDB 缓存用户材料。

### 5.2 网络白名单门禁

M7-05 若增加静态数据 `fetch`，现有“全部禁止”门禁必须改为关闭式白名单：

- 请求只能使用相对同源路径；
- 路径必须落在版本化的公开数据目录；
- 方法只能是 `GET`；
- 不允许 body、自定义身份请求头、用户输入查询参数或 credentials；
- 响应只按公开 Schema 解析；
- 非白名单请求继续阻断构建；
- 浏览器实测必须记录完整请求清单并确认请求载荷不含用户材料。

## 6. 不可信文件与内容安全

### 6.1 文件解析

- 在加载 PDF.js 或 Mammoth 前验证扩展名、文件头、大小、空文件和格式一致性；
- 上限继续保持 10MB，不能依赖浏览器内存耗尽后再失败；
- PDF 禁止执行 JavaScript、表单动作、附件和外部资源；
- DOCX 只提取纯文本，不插入解析后的 HTML，不加载图片、宏、模板或外部对象；
- TXT 只做字符编码与文本规范化；
- 文件名只作为普通文本显示，必须依赖 React 转义，不拼接进 HTML；
- 解析器异常只映射到固定错误码和安全提示，不展示堆栈、内存对象或原文片段；
- Worker 结束、取消、超时和清除时释放二进制引用。

### 6.2 XSS 与代码执行

生产源码和构建门禁禁止：

- `dangerouslySetInnerHTML`、业务代码中的 `innerHTML`；
- `eval`、`new Function` 和字符串形式的计时器；
- 未审核的动态脚本、JSONP、远程模块和运行时 CDN；
- 把用户内容插入样式、URL、事件处理器或可执行属性；
- 对用户输入使用 `javascript:`、`data:text/html` 或非 HTTPS 外链；
- 未经白名单验证就把公开数据中的 URL 渲染成链接。

如果依赖内部包含动态代码能力，必须证明该路径不会在浏览器生产流程被调用，并记录版本、原因和替代方案评估。

## 7. CSP 与静态托管安全头

### 7.1 建议生产策略

实际策略需在 Chrome、Edge、Safari 和打印流程中验证，推荐起点：

```text
default-src 'self';
script-src 'self';
style-src 'self' 'unsafe-inline';
img-src 'self' data:;
font-src 'self';
connect-src 'self';
worker-src 'self' blob:;
object-src 'none';
base-uri 'self';
form-action 'self';
frame-ancestors 'none';
manifest-src 'self';
```

说明：

- `style-src 'unsafe-inline'` 只在当前 React 行内样式确有需要时保留，后续优先通过 CSS 类移除；
- `blob:` 只在 Worker 或本地文件处理实测需要时保留；
- 不添加外部脚本、字体或解析器域名；
- `frame-ancestors` 必须通过 HTTP 响应头下发，不能依赖 meta 标签；
- 本地开发可以使用独立宽松策略，但生产策略不得因开发服务器需求放宽。

### 7.2 其他响应头

生产环境至少验证：

- `Content-Security-Policy`；
- `X-Content-Type-Options: nosniff`；
- `Referrer-Policy: no-referrer`；
- `Permissions-Policy` 禁止相机、麦克风、地理位置等未使用能力；
- `Strict-Transport-Security`，仅在正式 HTTPS 域名和子域策略确认后启用；
- 防止被第三方页面嵌入的 `frame-ancestors 'none'`；
- HTML 不应长期强缓存，带哈希静态资源可以 immutable 缓存；
- 静态知识 JSON 使用版本化或可控再验证缓存。

不要为了“头越多越安全”启用未经验证的 COEP/COOP/CORP，以免破坏文件解析、打印或外部链接；需要时必须单独评估。

## 8. 外部链接与公开数据

- 公司招聘入口只能来自 M5 白名单和已发布数据包；
- 链接必须是 HTTPS，禁止重定向到非白名单协议；
- 新窗口链接使用 `rel="noopener noreferrer"`；
- 页面不得向外部招聘网站附加用户方向、简历或报告参数；
- 链接文字、发布方、核验日期和过期状态必须保持可见；
- 过期数据保留为“待自行核实”，不能伪装成实时在招；
- 浏览器跳转前不执行追踪请求或中转服务；
- 公开数据中的 HTML、Markdown 或脚本内容一律按普通文本处理。

## 9. 存储、缓存与清除

- 只允许版本化、无敏感信息的流程位置写入 `sessionStorage`；
- 禁止原始文件、解析文本、事实、JD、画像、报告、行动状态和密钥进入 localStorage、sessionStorage、IndexedDB、Cache Storage、Cookie 或 URL；
- 页面刷新、关闭和一键清除后，敏感内存状态不可恢复；
- 解析 Worker、AbortController、对象 URL 和 BYOK 闭包在清除时统一销毁；
- 清除流程不得重新把初始状态写回敏感存储；
- 已复制到系统剪贴板或用户保存到设备的 PDF 必须继续明确不受网页清除控制；
- 不注册会缓存页面敏感状态的 Service Worker；如未来引入 PWA，必须另立安全评审。

## 10. 日志、错误与导出脱敏

### 10.1 日志

- 生产代码不得记录文件对象、正文、JD、事实内容、报告、密钥或完整异常对象；
- 控制台只允许固定错误码、模块名和不含用户数据的状态；
- Worker 错误通过关闭式代码传递，不透传堆栈或解析器内部对象；
- 构建和测试日志使用匿名样本，不输出真实文件路径中的个人信息；
- 当前 MVP 不接入第三方日志、分析和会话回放。

### 10.2 页面、剪贴板与打印

- 预览、证据追溯、复制文本和打印报告默认使用脱敏内容；
- 姓名、电话、邮箱、身份证号和详细地址不得因错误边界或展开组件重新暴露；
- BYOK 输入始终使用密码控件，不显示完整值，不进入复制与打印；
- 打印版不得包含隐藏表单、原始文件名中的敏感信息或调试状态；
- 复制失败和打印异常不能回退为复制/打印原始页面 DOM。

## 11. 依赖与供应链

### 11.1 版本与安装

- 生产依赖使用精确版本，不能长期依赖 `latest` 范围；
- 保留并验证单一锁文件，CI 使用冻结锁文件安装；
- 不运行来源不明的安装脚本或手工修改 `node_modules`；
- 核验包名、发布者、许可证、下载来源和完整性；
- PDF.js、Mammoth、React、ReactDOM 和图标库升级必须经过定向回归；
- 删除未使用的直接依赖，避免供应链面无意义扩大。

### 11.2 漏洞门禁

- 生产依赖 Critical/High 漏洞默认必须为 0；
- Moderate 漏洞必须确认是否进入浏览器生产路径；
- 无法立即升级的风险必须记录漏洞编号、影响路径、缓解措施、负责人和到期日；
- 不能使用 `--force` 自动升级并跳过功能回归；
- 安全审计结果需与实际锁文件和生产依赖树对应；
- 输出精简的第三方组件与许可证清单，保留版本和审核日期。

## 12. 构建与发布产物

- 生产 source map 默认不公开；如确需保留，只能进入受控内部存储；
- `dist/` 不包含 `.env`、测试夹具、维护草稿、内部复核记录、日志或临时文件；
- 构建产物只包含发布需要的静态页面、哈希资源和公开知识数据；
- 生产 HTML 不引用开发服务器、localhost、临时端口或本机绝对路径；
- 所有脚本和 Worker 从同源哈希资源加载；
- 构建后再次执行密钥、危险 API、网络、存储和 source map 扫描；
- 发布包生成可复核的文件清单与 SHA-256 摘要；
- M7-08 发布时使用相同产物，禁止在验收后手工替换文件。

## 13. 自动化安全门禁

现有 `validate:privacy` 应扩展或配合独立门禁，至少覆盖：

- 源码与构建产物秘密值扫描；
- `dangerouslySetInnerHTML`、`innerHTML`、`eval`、`new Function` 和远程脚本扫描；
- 网络调用关闭式白名单；
- 敏感持久化、URL 状态、Cookie、Cache Storage 和 Service Worker 写入扫描；
- 密钥日志、DOM、错误、剪贴板和打印反射检查；
- 外链协议、hostname、`target` 与 `rel` 校验；
- 生产 source map、开发地址和本机路径扫描；
- CSP 与安全响应头配置验证；
- 生产依赖漏洞与精确版本检查；
- 发布目录内容白名单和摘要生成。

任何允许列表都必须精确到文件、路径或调用封装，不得用“忽略整个目录”绕过门禁。

## 14. 人工动态检查

自动化之外至少执行：

1. 打开浏览器开发者工具，记录完整主流程网络请求；
2. 分别走粘贴、TXT、PDF、DOCX、无 JD、有 JD、报告、打印和清除；
3. 确认请求 URL、query、headers 和 body 无用户材料；
4. 检查 localStorage、sessionStorage、IndexedDB、Cache Storage、Cookie 和 URL；
5. 在解析失败、Worker 失败、动态模块失败时检查控制台；
6. 输入 HTML、脚本标签、长文件名、特殊 Unicode 和公式样式文本，确认只按文本显示；
7. 检查外部公司链接没有附加个人参数；
8. 检查 CSP 开启后解析、Worker、复制、打印和公开数据读取均正常；
9. 清除数据后再次检查内存可见状态和浏览器存储；
10. 对实际准备发布的 `dist/` 重新执行所有扫描。

## 15. 缺陷等级

| 等级 | 定义 | 示例 | 发布处理 |
|---|---|---|---|
| P0 | 可导致秘密或用户材料泄露、任意代码执行 | 构建内含真实密钥；简历被发送；可执行 XSS | 立即停止发布 |
| P1 | 关键安全控制缺失或可稳定绕过 | 无 CSP；敏感报告持久化；高危生产依赖 | M7-06 结束前修复 |
| P2 | 有缓解措施但仍需治理 | 中危依赖进入非关键路径；响应头不完整 | M7-07 前关闭或书面接受 |
| P3 | 低影响加固项 | 非敏感错误信息过多；冗余权限策略 | 进入后续优化池 |

## 16. 验收用例

| 编号 | 场景 | 通过条件 |
|---|---|---|
| SEC-01 | 源码秘密扫描 | 无真实密钥、令牌、私钥和连接串 |
| SEC-02 | 构建产物秘密扫描 | HTML/JS/CSS/JSON/Worker 无秘密值 |
| SEC-03 | 简历网络检查 | 全流程请求中无文件、正文、事实或报告 |
| SEC-04 | 浏览器存储检查 | 只存在允许的无敏感流程位置 |
| SEC-05 | PDF/DOCX 恶意内容 | 不执行脚本、宏、HTML或外部对象 |
| SEC-06 | XSS 输入 | 脚本标签、属性和协议均作为文本或被拒绝 |
| SEC-07 | CSP | 开启后核心流程正常，违规请求被拒绝 |
| SEC-08 | 安全响应头 | 生产响应符合本任务要求 |
| SEC-09 | 外部链接 | HTTPS、白名单、noopener/noreferrer、无个人参数 |
