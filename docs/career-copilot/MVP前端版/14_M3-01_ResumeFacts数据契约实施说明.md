# M3-01 ResumeFacts 数据契约实施说明

> 完成日期：2026-08-09  
> 状态：已完成  
> 当前结构版本：`1.0.0`

## 1. 目标与结果

M3-01 建立了浏览器内事实提取、敏感字段遮罩、用户确认、时间线检查和后续规则分析共同使用的数据契约。

本任务只定义结构、创建器、校验器和分析入口边界，不提前实现 M3-02 的敏感字段识别、M3-03 的规则提取或 M3-04 的事实确认界面。

## 2. 根对象

`ResumeFacts 1.0.0` 包含：

| 字段 | 作用 |
|---|---|
| `schemaVersion` | 固定为 `1.0.0`，未知版本拒绝使用 |
| `document` | 文档 ID、PDF/DOCX/TXT/粘贴/手工来源、字符数和原文长度 |
| `facts` | 可供用户确认的结构化事实 |
| `privateFields` | 敏感字段的遮罩值和来源位置 |
| `timelineFlags` | 日期异常提示及用户处理状态 |
| `review` | 整份事实确认的完成状态 |
| `createdAt` | 创建时间，UTC ISO 格式 |
| `updatedAt` | 最近修改时间，UTC ISO 格式 |

根对象不允许加入 `rawText`、文件对象、文件名、联系方式原值或其他未声明字段。

## 3. 七类事实

### `education`

学校、学历、专业、日期范围和亮点。

### `internship`

组织、岗位、地点、日期范围、个人动作、方法、结果和量化指标。

### `project`

项目名称、角色、日期范围、个人动作、方法、结果、指标和技术工具。

### `campus`

校园组织、角色、日期范围、动作和结果。

### `skill`

技能名称、水平、关键词及能证明该技能的其他事实 ID。

### `certification`

证书名称、颁发方、获得日期、过期日期和凭证编号。

### `achievement`

成果或奖项名称、颁发方、获得日期、级别和说明。

所有类别采用固定字段集合。数组字段在每次创建时独立生成，不共享可变默认值。

## 4. 通用事实字段

每条事实包含：

- `id`：由提取器或用户操作层提供的稳定 ID；
- `category`：七类事实之一；
- `data`：分类对应的固定载荷；
- `sourceRefs`：一个或多个原文位置引用；
- `confidence`：`high`、`medium`、`low`，可附带 0–1 分数和固定原因码；
- `review`：`pending`、`confirmed`、`excluded`、`uncertain`；
- `provenance`：`extracted`、`user_added`、`user_edited`。

提取生成的事实必须至少有一个来源引用。用户新增事实可以没有原文位置。用户做出确认、排除或不确定判断后必须记录更新时间。

## 5. 来源引用

`sourceRefs` 记录：

- `documentId`；
- `startOffset`、`endOffset`；
- PDF 页码或 `null`；
- 章节名称或 `null`。

偏移量按 JavaScript UTF-16 字符位置计算，与 `text.slice(startOffset, endOffset)` 一致。校验器检查文档 ID 一致、区间为正且不超过 `document.textLength`。

结构不复制原文摘录。事实确认页需要展示原文时，应从仍在内存中的解析文本按区间即时读取。

## 6. 日期与时间线

规范日期使用：

```json
{
  "value": "2026-08",
  "precision": "month"
}
```

支持 `year`、`month`、`day` 和 `unknown`。校验器检查精度与格式一致，并拒绝 2 月 31 日等不存在日期。

日期重叠、无效、缺失和冲突保存在 `timelineFlags`。每条提示必须引用现有事实 ID，并提供 `open`、`confirmed` 或 `dismissed` 状态。时间线提示只要求用户核实，不自动认定简历造假。

## 7. 敏感字段边界

`privateFields` 为 M3-02 预留以下类型：

- 姓名；
- 电话；
- 邮箱；
- 详细地址；
- 身份证号；
- 其他需要遮罩的字段。

每项只允许保存 `maskedValue`、来源区间、置信度和用户处理状态。`rawValue` 等未声明字段会触发校验错误。敏感字段与普通求职事实分开，不会被 `selectConfirmedFacts` 返回。

## 8. 分析入口规则

`selectConfirmedFacts()` 只返回 `review.status = confirmed` 的普通事实：

- `pending` 不参与；
- `uncertain` 不参与；
- `excluded` 不参与；
- `privateFields` 永不进入该入口。

这为 MFR-023“只有已确认事实进入核心结论”提供了代码级边界。

## 9. 校验策略

校验器返回固定错误码和 JSON 路径，不返回字段内容。主要检查：

- 精确结构版本；
- 根对象及所有子对象的关闭式字段集合；
- 文档格式、字符数和原文长度；
- 七类事实的必需字段和数据类型；
- 唯一事实 ID；
- 来源文档和区间完整性；
- 置信度、确认状态和时间戳；
- 日期精度及真实日历日期；
- 技能证据和时间线提示的事实引用；
- 敏感字段不得携带原值。

未来出现不兼容字段或语义变化时必须提升 `schemaVersion` 并增加显式迁移器，不能静默接受。
