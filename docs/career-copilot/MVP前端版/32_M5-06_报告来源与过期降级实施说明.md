# M5-06 报告来源与过期降级实施说明

> 完成日期：2026-08-14  
> 运行时模型：`CompanyRoleRecommendations 1.0.0`  
> 展示位置：真实诊断报告的四层投递策略之后

## 1. 交付结论

30 家公司目标池已接入真实报告。系统根据用户选定或自动识别的首发方向，展示 5 家带来源的公司目标；每张卡均可打开官方招聘入口，并明确显示核验日期和有效截止日。

本功能不把公司直接塞进冲刺、主申、稳妥或探索。四层继续描述投递资源组合，公司目标池只提供下一步需要核验的候选范围。

## 2. 卡片字段

每张卡固定显示：

- 公司名称；
- 标准岗位方向；
- 实习或校招方向；
- 官方来源标题；
- 核验日期；
- 有效截止日；
- 官方招聘入口；
- 当前核验状态和申请前核验提示。

页面不显示职位名称、地点、薪资、截止日期或实时开放状态，因为当前目标池没有岗位级来源可以支持这些事实。

## 3. 选择规则

```text
本次方向 ID
  → 筛选相同岗位方向的目标池记录
  → 优先排列与用户所选实习/校招类型一致的入口
  → 最多展示 5 家
```

类型不同的入口不会被隐藏，因为同一官方校招站通常同时承载实习与校园项目，但用户仍需在打开后核实具体批次。

## 4. 时效状态

运行时按中国标准时间比较：

- 数据集 `validThrough`；
- 公司记录 `expiresAt`；
- 公开来源 `expiresAt`；
- 招聘入口 `expiresAt`。

截止日当天仍显示“入口已核验”。从次日起，只要任一层过期，整张卡降级为“待自行核实”。降级卡仍保留官方链接、原核验日期和到期日，方便用户完成复核；页面同时显示总警告，不允许用户把卡片理解为在招信息。

## 5. 安全边界

- 无对应方向时返回空状态，不虚构公司；
- 不输出公司永久层级、排名、分数、成功率或录取概率；
- 不声明任何具体岗位 `open`；
- 不因公司名称推断岗位；
- 不自动访问招聘官网，不绕过登录或验证码；
- 官方链接使用新窗口打开，不携带简历或用户事实。

## 6. 自动验证

新增 8 项领域模型测试和 3 项组件测试，并扩展真实流程测试，覆盖：

- 六方向中单一方向返回 5 家目标；
- 实习/校招排序；
- 来源、入口、核验日期和截止日完整；
- 到期日当天有效、次日降级；
- 过期后链接仍保留；
- 未覆盖方向不虚构结果；
- 禁止档位、排名、分数和实时职位字段；
- 当前、过期和空状态的页面呈现；
- 用户完整流程中可看到 5 个官方招聘入口。

## 7. 下一任务

M5-07 将建立内部顾问维护流程，规范源数据编辑、人工复核、构建验证、发布与到期续期，避免知识库依赖开发者临时改 JSON。
