# M3-03 本地事实与时间线规则提取实施说明

> 完成日期：2026-08-10  
> 状态：已完成  
> 章节、日期与事实提取器版本：`1.0.0`

## 1. 目标与结果

M3-03 将浏览器解析出的简历正文转换成 `ResumeFacts 1.0.0` 待确认事实。提取过程不依赖账号、后端、数据库、网络请求或大模型，并默认运行在独立 Web Worker 中。

当前覆盖教育、实习、项目、校园、技能、证书、成果/奖项七类事实，以及日期缺失、无效日期、起止冲突和同类经历重叠四类时间线提示。材料页已展示提取数量和时间提示数量；事实编辑确认界面属于 M3-04。

## 2. 处理管线

```text
浏览器解析正文
  ↓ 本地敏感字段识别
章节标题识别 / 无标题保守推断
  ↓
章节内经历条目切分
  ↓
字段、日期、动作、结果、指标与工具提取
  ↓
来源区间与 PDF 页码回链
  ↓
置信度和时间线待核实提示
  ↓
ResumeFacts 1.0.0（全部 pending）
```

提取器不会把简历正文、文件对象或文件名写入 `ResumeFacts`。结构化事实可以包含与求职相关的学校、公司、岗位、动作和成果，但已识别的姓名、联系方式、身份证号和详细地址会在写入前遮罩。

## 3. 章节与条目规则

支持的中文/英文标题包括：

| 类别 | 典型标题 |
|---|---|
| 教育 | 教育经历、教育背景、Education |
| 实习 | 实习经历、工作经历、Work Experience |
| 项目 | 项目经历、研究经历、Projects |
| 校园 | 校园经历、学生工作、Leadership |
| 技能 | 专业技能、技能、Technical Skills |
| 证书 | 证书、资格证书、Certifications |
| 成果 | 荣誉奖项、获奖经历、Awards、Honors |

有明确标题时，标题信号进入置信度原因。没有标题时，只有包含学校、公司、项目、社团、证书、奖项或技能等强信号的非空段落才被推断，并降低置信度。

同一章节内优先按空行切分；没有空行时，通过日期以及“组织 + 岗位”式头部识别下一条经历。项目正文里的普通项目符号不会被当作新经历。

## 4. 七类事实字段

- 教育：学校、学历、专业、日期范围和教育亮点；
- 实习：组织、岗位、城市、日期、动作、方法、结果和量化指标；
- 项目：项目名、角色、日期、动作、方法、结果、指标和技术工具；
- 校园：组织、角色、日期、动作和结果；
- 技能：技能名、熟练度、关键词和后续证据引用位；
- 证书：名称、颁发方、获得/过期日期和凭证编号；
- 成果：标题、颁发方、日期、级别和说明。

无法可靠识别的字段保持 `null` 或空数组，不会根据常识补造。所有事实初始状态为 `pending`，来源类型为 `extracted`。

## 5. 来源与置信度

每条事实至少包含一个 `sourceRef`：文档 ID、UTF-16 起止区间、章节，以及可以可靠映射时的 PDF 页码。来源展示时从仍在内存中的正文按区间读取，不在事实对象里复制整段原文。

置信度由可解释信号组成：

- `section_heading` 或 `section_inferred`；
- `primary_field_detected`；
- `date_range_detected`；
- `item_boundary_detected`。

分数达到 0.80 为高置信，0.58–0.79 为中置信，其余为低置信。置信度仅表示规则识别可靠度，不表示履历真实性或候选人能力。

## 6. 日期与时间线

日期支持年、年月和完整日期，兼容 `2024.06`、`2024/06`、`2024-06`、`2024年6月`、年份区间和“至今”。不存在的月份或日期不会进入规范日期。

时间线提示包括：

- `date_missing`：教育、实习、项目或校园事实没有日期；
- `date_invalid`：出现 13 月、2 月 30 日等无效日期；
- `date_conflict`：开始日期晚于结束日期；
- `date_overlap`：两条教育事实或两条实习事实时间重叠。

所有提示初始状态均为 `open`，只要求用户核实。项目与实习、校园与教育等合理并行关系不触发重叠提示，系统也不会自动认定造假。

## 7. Worker 与降级

事实提取使用独立模块 Worker：

- 默认超时 15 秒；
- 成功、失败、取消或超时后立即终止线程；
- 页面解析控制器同时取消文件解析和事实提取；
- Worker 崩溃、协议错误和提取失败只返回固定错误码，不返回正文或底层异常；
- 浏览器完全缺少 Worker API 时，才动态加载同一纯函数在本地执行。

生产构建将事实提取 Worker 拆为 19.83 kB 独立资源；无 Worker 降级模块为 18.45 kB，gzip 7.08 kB，不进入正常首屏执行路径。

## 9. 已知边界

- 基于规则而非语义模型，非标准排版或极度简写可能漏识别；
- 当前只内置常见工具名，长尾技能仍依赖清晰的技能章节和分隔符；
- PDF 页码只有在解析页文本能与合并正文可靠对齐时填写，否则为 `null`；
- 时间线重叠仅提示核实，不判断兼职、交换、双学位或并行实习是否合理；
- 当前事实页仍是结构示例，真实事实的增删改、确认、排除和来源展开属于 M3-04。
