# 纯前端 MVP PRD

> 状态：当前生效  
> 约束：无账号、无业务后端、无数据库、无品牌模型密钥

## 1. 主流程

1. 用户从 MoreThan 官网进入智能求职助手。
2. 阅读本地处理和能力边界说明。
3. 导入 PDF/DOCX/TXT 或粘贴简历文本。
4. 浏览器本地解析，展示识别到的事实和低置信项。
5. 用户确认、修改或排除事实。
6. 选择实习/校招、岗位方向、城市和时间窗口。
7. 可选粘贴目标 JD；没有 JD 时使用岗位族规则。
8. 本地规则引擎生成诊断报告。
9. 用户查看证据、公司岗位分层和行动计划。
10. 用户复制、打印、导出或清除本次数据。

## 2. 功能需求

### 2.1 入口与说明

**MFR-001 P0** 官网主导航和首页必须存在一级入口。  
**MFR-002 P0** 入口明确说明“简历默认仅在当前设备处理”。  
**MFR-003 P0** 区分“本地规则分析”和“AI 模型生成”。  
**MFR-004 P0** 明确不提供录用保证、实时在招保证或录取概率。

### 2.2 本地文件处理

**MFR-010 P0** 支持 PDF、DOCX、TXT 和文本粘贴。  
**MFR-011 P0** 文件解析必须在浏览器中完成，不上传至 MoreThan 服务器。  
**MFR-012 P0** 单文件建议不超过 10MB、20 页。  
**MFR-013 P0** 解析失败必须说明格式、扫描件、加密或文本缺失等原因。  
**MFR-014 P0** 图片扫描件首版可以不支持，但必须给出转为可复制文本的提示。  
**MFR-015 P0** 本地识别姓名、电话、邮箱和详细住址，并在报告中默认遮盖。

### 2.3 事实确认

**MFR-020 P0** 提取教育、实习、项目、校园经历、技能、证书和成果。  
**MFR-021 P0** 每条事实显示来源段落和识别置信度。  
**MFR-022 P0** 用户可以修改、删除或排除事实。  
**MFR-023 P0** 只有已确认事实进入核心结论。  
**MFR-024 P0** 检测时间重叠和异常日期，但不自动认定造假。

### 2.4 目标采集

**MFR-030 P0** 只提供实习和校招。  
**MFR-031 P0** 用户选择一个主投方向和最多两个备选方向。  
**MFR-032 P0** 采集目标城市、开始投递时间和硬约束。  
**MFR-033 P0** 不询问与岗位无必要关系的婚育、民族、宗教或健康信息。  
**MFR-034 P0** 支持粘贴一份目标 JD。

### 2.5 本地诊断

**MFR-040 P0** 检查每段经历是否包含动作、方法、结果和规模。  
**MFR-041 P0** 识别数字成果、效率、质量和影响范围证据。  
**MFR-042 P0** 识别空泛、重复和缺少个人贡献的表达。  
**MFR-043 P0** 对照 JD 提取任务词、技能词和门槛词。  
**MFR-044 P0** 输出最多 3 项优势、3 项问题和 5 项近期行动。  
**MFR-045 P0** 明确区分能力不足、证据不足和信息不足。  
**MFR-046 P0** 每项结论显示触发规则、引用证据和置信度。  
**MFR-047 P0** 不输出单一求职竞争力总分和精确录取概率。

### 2.6 公司岗位分层

**MFR-050 P0** 分层对象是公司 × 岗位族 × 地点 × 招聘类型。  
**MFR-051 P0** 使用冲刺、主申、稳健、探索四层。  
**MFR-052 P0** 每条数据来自随网站发布的审核静态知识包。  
**MFR-053 P0** 显示来源、最近核验日期和是否需要前往官网确认。  
**MFR-054 P0** 过期数据不得显示为确定的“正在招聘”。  
**MFR-055 P0** 用户可排除公司、城市和行业并在本地重算。  
**MFR-056 P0** 稳健层固定提示不保证面试或 offer。

### 2.7 报告与导出

**MFR-060 P0** 报告包含 30 秒结论、背景事实、优势、问题、方向、公司岗位池和行动计划。  
**MFR-061 P0** 支持复制文本和浏览器打印。  
**MFR-062 P0** 支持通过打印生成 PDF，或实现纯前端 PDF 导出。  
**MFR-063 P0** 默认不在导出报告中包含姓名、电话、邮箱和完整简历原文。  
**MFR-064 P0** 报告标明规则库版本、知识包版本和生成时间。

### 2.8 本地数据控制

**MFR-070 P0** 页面明确说明哪些数据仅存内存、哪些存 sessionStorage/localStorage。  
**MFR-071 P0** 原始简历正文默认只在内存中，刷新或关闭后清除。  
**MFR-072 P0** 用户可一键清除当前分析状态。  
**MFR-073 P0** 默认不使用第三方统计工具记录自由文本、文件名或诊断内容。  
**MFR-074 P0** 埋点只记录页面、步骤、错误类型和匿名计数。

### 2.9 可选 BYOK 实验模式

**MFR-080 P1** 用户可以选择输入自己拥有的兼容模型 API 密钥。  
**MFR-081 P1** 密钥只保存在 JavaScript 内存中，不进入 localStorage、日志或 URL。  
**MFR-082 P1** 调用前明确告知简历内容将直接发送到用户选择的模型供应商。  
**MFR-083 P1** 供应商不支持浏览器跨域调用时，明确提示不可用，不绕过安全限制。  
**MFR-084 P1** 不提供或暗示共享、破解、代充密钥。  
**MFR-085 P1** 本地规则版始终可用，不以 BYOK 为完成流程的必要条件。

## 3. 非功能需求

- 首屏加载：常见网络下目标 ≤ 3 秒；
- 解析：普通文本型简历目标 ≤ 10 秒；
- 规则分析：目标 ≤ 3 秒；
- 文件和正文不产生网络请求；
- 支持最新版 Chrome、Edge、Safari；
- PC 为主，移动端可完成文本粘贴和报告阅读；
- 键盘可操作，主要文字满足 WCAG AA 对比度；
- 任一步骤失败都可返回修改，不要求重新开始；
- 静态站点构建失败不得发布。

## 4. MVP 上线阻断项

- 任何简历正文意外发送到统计、日志或外部服务；
- 在前端代码中出现 MoreThan 的模型 API 密钥；
- 规则结论没有证据或触发原因；
- 公司岗位数据没有来源或核验日期；
- 扫描件被错误识别后仍生成肯定结论；
- 删除/清除按钮不能真实清除浏览器状态；
- 手机端无法退出或清除数据；
- 报告把稳健层表述为保 offer。
