# M6-04 一键清除本次数据实施说明

## 1. 完成范围

M6-04 将此前只重置流程位置的操作升级为统一会话清理。用户在“数据与设置”页面二次确认后，网页会：

1. 终止仍在运行的简历解析和事实提取；
2. 清空简历文件名、提取文本、敏感字段识别结果和结构化事实；
3. 清空求职目标、JD、画像分析、差距分析、四层建议、公司目标池、行动计划和来源索引；
4. 释放已登记的临时对象 URL 与其他会话资源；
5. 清除求职助手命名空间下的 sessionStorage、localStorage、Cache Storage、IndexedDB 和 Cookie；
6. 返回助手开始页，并提示数据已清除且无法恢复。

## 2. Worker 和异步保护

简历解析 Worker 与事实提取 Worker 已经通过同一个 `AbortController` 串联。本任务新增统一资源登记器：

- 新解析开始时登记控制器；
- 正常完成后取消登记；
- 用户清除、切换材料或页面卸载时统一中止；
- Worker 客户端收到中止信号后执行已有的 `terminate()`、计时器和事件监听清理；
- 清除后递增文档序列，旧异步结果不能作为当前文档继续使用。

## 3. 临时资源

当前产品流程尚未创建 Blob 对象 URL，但清理器已提供对象 URL 登记与 `URL.revokeObjectURL()` 能力。后续若文件预览或导出引入临时 URL，必须先登记，才能由一键清除和页面卸载统一释放。

## 4. 浏览器存储边界

清除器只删除以下命名空间：

- `morethan-career-copilot`
- `morethan-career-copilot-*`
- 已知旧版求职助手键

不会清除 MoreThan 官网其他功能的数据、主题偏好或第三方站点数据。浏览器不支持 Cache/IndexedDB 枚举时按零残留的现有能力安全降级，不阻塞内存清除。

## 5. 确认交互

- 第一次点击只打开不可逆操作说明，不立即删除；
- 对话框默认聚焦“取消，保留数据”；
- 明确列出将被清除的内存、Worker 和浏览器命名空间；
- 确认按钮明确写明“不可恢复”；
- 执行期间按钮锁定，避免重复提交；
- 点击遮罩或关闭按钮可以安全取消。

## 6. 无法代替用户清除的内容

以下内容已经离开网页控制范围，不能由一键清除删除：

- 用户复制到操作系统剪贴板的脱敏报告；
- 用户通过浏览器打印保存到设备上的 PDF；
- 用户自行截图、转发或另存的内容。

页面已对此作显式说明。

## 7. 验收要点

- 未确认时不会删除任何数据；
- 确认后返回开始页且流程存储保持为空；
- 当前所有分析状态和报告状态被重置；
- 活跃控制器被中止，关联 Worker 随信号终止；
- 登记的对象 URL 被撤销且不会重复撤销；
- 只删除求职助手命名空间，不影响官网其他设置；
- 清除后明确提示“无法恢复”。
