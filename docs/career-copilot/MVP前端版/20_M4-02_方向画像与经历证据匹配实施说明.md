# M4-02 方向画像与经历证据匹配实施说明

> 完成日期：2026-08-13  
> 状态：已完成  
> 范围：方向画像、经历证据匹配与报告首屏接入；不包含 JD 解析和公司分层

## 1. 完成结果

用户完成事实确认后，可以选择首发六类岗位方向或“请先帮我判断”。浏览器本地分析器会把已确认事实映射为方向相关性和七类证据，输出最多 3 项优势、3 项简历证据短板，以及证据不足时的降级结论。

真实流程的报告首屏现已读取本次分析结果，不再显示固定示例判断。首页单独进入的示例报告仍保留，但明确标注为示例。

## 2. 首发方向

- 产品经理；
- 产品/用户运营；
- 市场/品牌/增长；
- 软件研发；
- 数据分析/商业分析；
- 金融/财会通用。

画像版本为 `1.0.0`。每类画像通过任务词和技能词计算证据覆盖，用于方向排序，不代表岗位胜任认证。

## 3. 分析边界

- 输入必须是有效的 `ResumeFacts 1.0.0`；
- 分析器只读取 `selectConfirmedFacts()`，明确排除待确认、不参与分析和无法确认事实；
- 每条证据保留事实 ID 和命中字段路径；
- 每条结论保留规则 ID、证据 ID、事实 ID、置信度、边界说明与下一动作；
- 优势必须有直接事实证据；
- 短板只表述为简历证据缺失或较弱，不推断用户不会或能力不足；
- 没有已确认事实时，七项规则全部降级为信息不足；
- 内部得分仅用于排序，不对用户展示单一总分或录取概率。

## 4. 页面闭环

目标页现支持真实选择实习/校招和七个方向选项（六类岗位族加自动判断）。用户提交关键追问后，页面在内存中执行分析；生成页明确显示本地规则处理，报告页引用事实摘要、已确认事实数量和触发规则。

用户返回纠正事实时会清除旧分析结果，避免用修改前的事实继续展示结论。重置流程同样清除目标与分析内存。
