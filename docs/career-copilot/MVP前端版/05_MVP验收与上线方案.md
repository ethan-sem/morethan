# MoreThan 智能求职助手：MVP 验收与上线方案

> 版本：MVP-FE-v1.0  
> 适用对象：产品、前端、内容顾问、测试和发布负责人  
> 核心标准：无需账号、无需后端，普通用户打开网页即可完成一次有用且安全的求职诊断

## 1. 上线定义

MVP 的“上线”不是只有页面可访问，而是同时满足：

1. 用户能输入或本地解析简历内容；
2. 用户能核对系统读取到的事实；
3. 用户能选择实习/校招方向并按需粘贴 JD；
4. 系统能在浏览器内生成有证据、有边界的完整报告；
5. 用户能复制或打印报告，并清除本次数据；
6. 未经用户主动操作，简历及报告不会发送到网络或持久化；
7. 页面在 MoreThan 官网生产环境稳定可访问并可回滚。

## 2. 发布门禁

所有 P0 项必须通过；P1 未通过时需由产品负责人书面接受并记录降级方案。

### 2.1 功能门禁（P0）

- 官网一级入口可进入助手，刷新和浏览器返回不产生死页。
- PDF、DOCX、TXT、粘贴文本和手工填写至少有明确可用或明确不支持的结果。
- 用户可以编辑系统提取的教育、经历、技能及目标信息。
- 报告至少包含：核心摘要、3–5 项优势、主要短板、方向判断、四层公司/岗位建议、48 小时/7 天/30 天行动计划。
- 每条关键结论能显示其依据类型；无依据时不得伪装为事实。
- JD 缺失时仍可生成通用方向报告；JD 存在时增加岗位差距分析。
- 复制、打印/PDF 和一键清除可用。

### 2.2 隐私与安全门禁（P0）

- 构建产物、源码、Source Map 和网络请求中不存在 MoreThan 模型密钥或其他长期凭据。
- 默认流程中，原始简历、解析文本和报告没有上传请求。
- 原始简历和报告不写入 localStorage、sessionStorage、IndexedDB、Cookie 或分析埋点。
- 清除后内存状态、临时文件引用和页面展示均被重置。
- 错误日志不包含简历正文、电话、邮箱、姓名或用户自带密钥。
- 上传控件限制文件类型和大小；文档内嵌脚本、宏、外链和对象不被执行。
- 页面展示隐私说明、生成方式、公开数据时效和“非录用保证”声明。

### 2.3 内容质量门禁（P0）

- 事实、推断与公开资料在数据结构和界面中可区分。
- 公司建议按岗位族和候选人证据生成，不以学校、性别、年龄等敏感属性作价值判断。
- 不输出确定录取概率、保 offer、保实习或歧视性结论。
- 每个公司/岗位公开事实有来源 URL 和核验日期；过期或缺失来源时显示降级提示。
- 至少由一名内部顾问复核规则阈值、四层推荐样例和行动建议。

### 2.4 兼容与体验门禁（P0）

- 桌面 Chrome、Edge、Safari 最近两个主版本完成主流程。
- 375 px 宽度移动页面无关键内容遮挡、横向溢出或不可点击控件。
- 所有核心操作可使用键盘完成；表单有标签；焦点和错误提示可感知。
- 解析过程中有状态反馈，耗时任务不冻结主线程。
- 打印版不包含导航、输入控件和无关按钮，正文不被截断。

### 2.5 性能门禁（P1）

- 静态知识数据按需加载，不把全部资料塞入首屏包。
- 首屏关键内容在常见 4G 网络下可接受；不因解析依赖显著阻塞官网其他页面。
- 5 MB 文本型简历在目标桌面设备上能完成解析且页面保持响应。
- 连续生成三次报告不出现明显内存持续增长。

## 3. 核心验收用例

| ID | 场景 | 预期结果 | 级别 |
|---|---|---|---|
| AC-01 | 首次访问，不登录 | 直接进入助手并开始填写 | P0 |
| AC-02 | 上传文本型 PDF | 本地解析并进入事实确认 | P0 |
| AC-03 | 上传扫描 PDF | 明确提示暂不支持 OCR，并提供粘贴/手填替代入口 | P0 |
| AC-04 | 上传损坏或加密文件 | 不崩溃、不上传，显示可恢复错误 | P0 |
| AC-05 | 修改提取错误的经历 | 报告只使用修改后的确认事实 | P0 |
| AC-06 | 不提供 JD | 生成方向级报告，明确未做特定岗位匹配 | P0 |
| AC-07 | 提供 JD | 输出要求拆解、证据匹配、缺口和行动建议 | P0 |
| AC-08 | 经历证据不足 | 输出条件式建议或补充信息提示，不编造事实 | P0 |
| AC-09 | 查看公司建议 | 显示四层结果、岗位族、理由、来源和核验时间 | P0 |
| AC-10 | 打印为 PDF | 报告结构完整且无导航/操作按钮 | P0 |
| AC-11 | 点击清除 | 当前资料和报告消失，存储与网络检查无残留 | P0 |
| AC-12 | 检查网络面板 | 默认完整流程没有简历/报告上传请求 | P0 |
| AC-13 | 移动端完成主流程 | 无阻断性布局或交互问题 | P0 |
| AC-14 | 公开数据已过期 | 标为待核实，不作为强推荐事实 | P0 |

## 4. 测试材料

测试必须使用虚构或充分匿名化材料，不使用真实用户简历进入代码仓库。

最小样本集：

- 理工科、有两段相关实习；
- 商科、项目多但缺少量化成果；
- 跨专业转产品/运营；
- 大一/大二、经历很少；
- 中文简历、英文简历和中英混合简历；
- 时间线冲突、联系方式密集、表格型排版；
- 扫描 PDF、加密 PDF、损坏 DOCX 和超限文件；
- 与目标高度匹配和明显不匹配的 JD 各一份。

## 5. 发布步骤

1. 锁定规则版本和静态知识数据版本。
2. 运行测试、构建、依赖检查和静态数据校验。
3. 在预览环境完成 P0 用例及桌面/移动检查。
4. 内容顾问抽检至少 10 份匿名样例报告并签字确认。
5. 检查生产配置、CSP、缓存策略、404 回退和回滚版本。
6. 获得用户明确发布授权后部署生产。
7. 生产冒烟测试：入口、解析、报告、打印、清除和网络请求。

## 6. 回滚与降级

- 若新功能影响官网：回滚至上一稳定构建。
- 若某文档解析器异常：关闭对应功能开关，保留粘贴与手工填写。
- 若公司数据失效：隐藏具体公司项，保留岗位族与选择方法。
- 若规则输出出现严重误导：停止报告生成，展示维护提示，不以旧缓存继续服务。
- 纯前端版本没有服务端数据迁移，回滚不得影响用户云端数据，因为本版不采集该数据。

## 7. 上线后观察

在不采集简历内容和敏感信息的前提下，可统计：

- 功能入口曝光与开始次数；
- 各步骤匿名事件计数及错误码；
- 报告生成、复制、打印和清除次数；
- 解析器类型、耗时区间和成功/失败结果；
- 用户主动提交的满意度与问题分类。

禁止将简历正文、JD 正文、报告正文、联系方式或用户自带密钥写入分析系统。
