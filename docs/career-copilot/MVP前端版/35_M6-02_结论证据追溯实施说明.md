# M6-02 结论证据追溯实施说明

## 1. 完成范围

M6-02 把 M4-07 已建立的结论来源索引转为用户可以直接核对的界面。报告和行动页中的关键结论不再只显示“已确认事实 / 规则推断 / 公开资料”标签；用户可以展开“查看判断依据”，看到本条结论实际引用的事实、规则和来源。

## 2. 追溯结构

每条已建立来源索引的结论可以展示：

1. 生成说明：区分已确认事实与本地规则判断；
2. 简历证据：事实类别、脱敏摘要、确认状态和来源位置；
3. 触发规则：稳定的规则编号；
4. 公开来源：来源标题、HTTPS 链接和核验日期；
5. 无证据边界：没有引用事实或公开来源时明确说明，不显示空的来源标签。

覆盖位置包括：

- 报告顶部摘要卡；
- 完整优势与短板；
- JD 差距卡；
- 四层投递建议；
- 报告内行动摘要；
- 独立行动计划页。

方向模块独立展示岗位画像版本与支撑该方向的已确认事实。公司目标池卡片独立展示进入目标池的原因、发布方、资料状态、记录类型和公开引用页面。

## 3. 隐私边界

- 证据面板只使用 `ResumeFacts` 中的脱敏结构化摘要，不展示完整简历原文；
- 不显示姓名、电话、邮箱、身份证号或详细地址；
- 来源位置只显示页码、章节或字符区间；
- 找不到已引用事实时保留事实 ID，明确标记“当前不可查看”，不凭空补写内容；
- 公开资料必须来自既有 HTTPS 来源并带核验日期。

## 4. 交互与无障碍

- 使用原生 `details` / `summary`，支持键盘展开和收起；
- 标签继续提供完整的无障碍来源说明；
- 来源状态同时使用文字，不只依赖颜色；
- 外部来源在新窗口打开，并保留安全的 `rel` 配置；
- 移动端证据面板随卡片宽度自然换行。

## 5. 验收要点

- 用户可从关键结论查看具体事实摘要和规则编号；
- 事实显示确认状态与材料位置；
- 未引用事实的结论明确说明无直接简历证据；
- 有公开来源时显示链接和核验日期，无来源时不伪造；
- 公司目标池可查看公开资料为何支持“进入目标池”，但不声称实时招聘；
- 展开内容不包含完整简历原文或敏感字段。
