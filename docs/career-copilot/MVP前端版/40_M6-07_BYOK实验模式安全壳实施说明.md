# M6-07 BYOK 实验模式安全壳实施说明

> 状态：已实施  
> 范围：纯前端 MVP 的可选实验入口；默认关闭；当前不调用任何模型 API

## 1. 本任务的边界

M6-07 只实现 BYOK 的用户授权、临时密钥管理和安全退出机制，不实现真实模型调用。这样可以先验证交互和密钥生命周期，同时避免在供应商浏览器调用政策、跨域能力、请求字段和内容外发同意尚未完成专项审核前发送简历。

本地规则版保持完整可用，不需要开启 BYOK，也不因 BYOK 是否配置而改变报告。

## 2. 开启条件

BYOK 受到两层默认关闭控制：

1. 部署功能开关 `VITE_COPILOT_BYOK` 默认为 `false`，关闭时页面不渲染实验入口；
2. 即使部署开关开启，用户仍须在“数据与设置”页勾选知情说明，才能主动开启密钥输入区。

知情说明明确告知：当前密钥仅驻留内存；未来只有用户主动调用时，所选内容才会直接发送给相应供应商并受其条款约束。

## 3. 密钥生命周期

- 密钥通过密码输入框录入，并使用 `autocomplete="new-password"`；
- 密钥只写入页面组件持有的闭包变量，不进入 React 可序列化业务对象；
- 页面状态只保存 `hasKey` 与供应商类型，不保存密钥或掩码片段；
- DOM、状态提示、错误信息和导出报告均不回显密钥；
- 密钥不能通过 `JSON.stringify` 导出；
- 主动清除密钥、关闭实验模式、一键清除数据、页面卸载或刷新均清除引用；
- 预留的 `consume(callback)` 采用单次使用语义，无论调用成功或失败都在 `finally` 中清除密钥。

## 4. 明确禁止

- localStorage、sessionStorage、IndexedDB、Cookie 或 Cache Storage 保存密钥；
- URL、路由状态或查询参数携带密钥；
- 日志、错误上报、分析埋点或 DOM 文本反射密钥；
- 在前端构建产物中内置 MoreThan 或共享供应商密钥；
- 使用公共代理绕过供应商 CORS 或安全策略；
- 暗示共享、破解、代充密钥；
- 未再次获得用户明确同意就发送简历、JD 或报告内容。

## 5. 当前界面状态

- 功能关闭：不显示 BYOK 实验区；
- 功能可用但未启用：显示“默认关闭”及知情确认；
- 用户主动启用：显示供应商类型和密码输入框；
- 密钥就绪：只显示“密钥已临时保存”，不显示内容；
- 用户可独立清除密钥或关闭实验模式；
- 一键清除本次数据同时清除 BYOK 状态。

## 6. 后续真实调用前置任务

真实模型调用不属于 M6-07。后续若开发，必须先逐供应商完成：官方浏览器调用政策核验、CORS 可用性验证、发送字段最小化、逐次发送确认、超时和撤销、错误脱敏、响应内容安全、费用提示及 CSP 域名收敛。任何一项不满足时维持本地规则版。

## 7. 验收标准

- 默认构建不显示实验入口；
- 开启构建仍要求用户主动勾选并点击开启；
- 密钥只存在当前页面内存且不回显；
- 关闭、清除、卸载或单次消费后密钥失效；
- 隐私门禁阻止密钥日志、DOM 反射、敏感序列化、持久化与默认网络发送；
- 本地规则流程不受影响；
- 自动化测试和生产构建全部通过。
