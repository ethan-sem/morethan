# M4-07 结论来源类型标记实施说明

> 完成日期：2026-08-13  
> 状态：已完成  
> 范围：画像、JD 差距、四层策略和行动计划的来源类型；不包含 M5 公开公司岗位数据建设

## 1. 完成结果

真实报告与行动页现在会在每条结论旁显示来源类型，用户可以直接区分哪些内容引用了自己确认的简历事实，哪些是浏览器规则形成的判断，以及未来哪些内容来自带链接的公开资料。

当前尚未接入 M5 审核知识库，因此页面不会为了凑齐三种类型而显示虚构的“公开资料”标签。

## 2. ConclusionProvenance 1.0.0

来源索引独立于既有画像、JD、四层和行动数据契约，避免为了展示字段破坏已稳定的上游结构。它按“目标类型 + 目标 ID”定位：

- `profile_conclusion`：优势、短板或信息不足结论；
- `jd_gap`：逐项 JD 对照结论；
- `tier_lane`：冲刺、主申、稳妥、探索泳道；
- `action_item`：三时间窗中的具体任务。

每项记录包含来源类型数组、事实 ID、规则 ID、公开来源数组和解释。根对象记录所有上游契约版本、文档 ID 和三类来源统计。

## 3. 三类来源边界

- 已确认事实：只有目标结论实际引用事实 ID 才显示；
- 规则推断：每个真实分析结论都必须显示，提醒用户这是规则判断而非履历原文；
- 公开资料：必须有 HTTPS 链接、标题和有效核验日期，且只能绑定到真实存在的目标结论。

JD 未命中、无 JD 收集任务等没有直接事实支撑的内容只显示“规则推断”。任务生成器也已去掉无关事实的兜底引用，防止误标来源。

## 4. 页面实现

报告首屏新增来源图例；画像卡、JD 差距卡、四层投递卡和行动任务分别渲染自己的来源胶囊。标签使用颜色和文字双重编码，不只依赖颜色区分，并通过 `aria-label` 提供完整的来源组合说明。

公开资料存在时可显示来源标题、链接和核验日期；链接使用新窗口打开并设置安全的 `rel` 属性。当前默认数据没有任何公开来源绑定，所以不会渲染链接。

## 5. 安全与校验

- 所有上游对象必须版本匹配，简历文档 ID 必须一致；
- 来源项和根对象采用关闭式字段校验；
- 来源类型不能重复，规则 ID 不得为空；
- 事实标签与事实 ID、公开资料标签与公开来源数组必须严格一致；
- 公开来源拒绝 HTTP、无效日期、未知字段、未知目标和重复目标绑定；
- 来源标签不改变原结论含义，不把规则判断包装为客观事实或录用保证。
