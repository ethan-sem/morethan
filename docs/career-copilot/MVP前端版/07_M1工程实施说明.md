# M1 前端工程基础实施说明

> 完成日期：2026-08-09  
> 状态：M1-01 至 M1-04 全部完成

## 1. 完成内容

- 将原 376 行单体页面拆成页面入口、通用组件、四组业务界面、流程领域模型、Hook、会话存储和功能配置。
- 建立显式流程状态机，处理下一步、上一步、已访问步骤、示例报告跳转、非法跳转、刷新恢复和重置。
- 建立助手独立错误边界，支持重试或清除流程后重新开始。
- 会话存储只保存 `version`、`step` 和 `visited`；文件名改为内存状态，刷新即消失。
- 建立四个独立功能开关：本地解析、JD 分析、报告打印和 BYOK；BYOK 默认关闭。
- 建立 ESLint、严格 JSDoc 类型检查、Vitest 单元测试和 React 组件测试。

## 4. 功能开关

示例值记录在项目根目录 `.env.example`：

- `VITE_COPILOT_LOCAL_PARSING=true`
- `VITE_COPILOT_JD_ANALYSIS=true`
- `VITE_COPILOT_REPORT_PRINTING=true`
- `VITE_COPILOT_BYOK=false`

功能开关不是密钥存储方案。任何模型 API 密钥都不得写入 `.env.example`、前端环境变量或构建产物。

## 5. M2 接入约束

M2 本地解析应接入 `MaterialScreen` 和独立解析模块，不得重新把解析逻辑堆入页面入口；原始文件和解析正文不得加入现有流程会话存储。
