# M5-04 岗位族与方向映射实施说明

> 完成日期：2026-08-14  
> 数据集：`RoleFamilyMap 1.0.0 / 2026.08.1`  
> 适用范围：中国大陆实习与校园招聘

## 1. 交付结论

新增 `public/data/career-copilot/role-family-map.json`，把六个首发求职方向拆分为 18 个可复用的细分岗位族。公司目标池仍只负责提供经过核验的招聘入口；岗位族映射层负责根据岗位名称和职责文本选择分析规则，两者不再混为一层。

本轮同时新增关闭式校验器和确定性匹配器。单纯输入“华为”“宝洁”等公司名不会命中任何岗位；只有职位名别名或足够的职责关键词证据才会产生候选。

## 2. 18 个细分岗位族

| 方向 | 细分岗位族 |
|---|---|
| 产品经理 | 用户产品、企业服务产品、平台/策略产品 |
| 产品/用户运营 | 用户/增长运营、内容/社区运营、产品/策略运营 |
| 市场/品牌/增长 | 品牌/整合传播、效果/增长营销、市场研究/营销策略 |
| 软件研发 | 前端、后端/服务端、移动端/客户端 |
| 数据分析/商业分析 | 数据分析/BI、商业/经营/战略分析、数据科学/算法 |
| 金融/财会通用 | 会计/审计/税务、财务分析/企业财务、投资研究/风险管理 |

每个岗位族包含常见职位名、三项核心任务、典型产出、简历证据信号、至少六个 JD 关键词、相邻岗位族、公开分类依据和顾问复核信息。

## 3. 映射规则

```text
职位名称 + 职责文本
  → 职位别名优先匹配
  → 无明确别名时至少命中 2 个职责关键词
  → 返回 1–3 个候选
  → 多候选或纯职责匹配时标记 needs_review
  → 无证据时 unmapped
```

匹配器不接受公司名称、学校、性别或年龄。输出只说明“应使用哪个岗位画像继续分析”，不说明候选人适合该岗位，更不代表公司存在实时职位。

## 4. 数据边界

- 不保存公司到细分岗位族的永久推断关系；
- 不因知名公司、行业标签或组织性质推断职位；
- 不输出录取概率、成功率、竞争力总分或永久档次；
- 不把职责关键词命中视为用户具备能力；
- 具体 JD、地点、招聘类型、毕业时间和开放状态仍需申请时核验；
- 岗位族映射的维护周期和公司岗位实时信息的 7 天周期相互独立。

## 5. 外部分类依据

本表以人力资源和社会保障部发布的《中华人民共和国职业分类大典（2022年版）》及数字职业信息校准职业边界，并使用 O*NET 公开职业分类交叉核对任务和产出。互联网校招中的职位名称与细分方式由 MoreThan 建立本地映射，不宣称等同于任何外部分类编码。

## 6. 自动验证

新增 10 项测试，覆盖发布状态、6×3 完整结构、岗位画像字段、30 家目标池兼容、职位名优先、职责证据匹配、公司名不参与、最多三个候选、引用完整性及关闭式 Schema。
