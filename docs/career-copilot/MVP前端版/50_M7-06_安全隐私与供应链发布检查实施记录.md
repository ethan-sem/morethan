## 1. 最终结论

M7-06 已完成，当前已知 P0/P1 为 0。安全控制不依赖人工记忆：源码检查在构建前运行，发布产物检查在 Vite 构建后运行，故意加入秘密值、动态执行、越界网络、敏感存储或 source map 时会以非零状态阻断完整检查。

本次没有部署到外部生产环境；M7-08 仍要求用户明确授权发布。生产域名的 HSTS 只能在 HTTPS 和子域策略确认后启用，不能在本地或未知域名上提前承诺。

## 2. 已完成实现

- 新增 `validate-career-security.js`，分别审计源码和最终 `dist/`。
- 秘密值扫描覆盖常见云密钥、模型密钥、私钥、令牌、数据库连接串和敏感高熵赋值。
- 禁止未授权 `fetch`、XHR、WebSocket、Beacon、敏感存储写入、Service Worker、Cookie、动态 HTML、`eval`、`new Function`、字符串计时器和远程脚本。
- 公司方向数据读取固定为相对同源公开目录、`GET`、无 body、无自定义头、`same-origin` 凭据、拒绝重定向和 `no-referrer`。
- 所有新窗口链接统一为 `noopener noreferrer`；公司数据仍经过 HTTPS 与来源白名单 Schema 校验。
- `vite.config.js` 明确关闭生产 source map。
- `public/_headers` 固化 CSP、`nosniff`、`no-referrer`、权限策略、防嵌入策略及 HTML/哈希资源/知识 JSON 的缓存规则。
- 所有直接依赖和开发依赖从 `latest`、`^` 范围改为当前锁文件中的精确版本，冻结单一 `pnpm-lock.yaml`。
- 新增依赖漏洞记录、直接生产组件许可证清单和逐文件 SHA-256 发布清单。
- 新增恶意 HTML/脚本/外部像素文本及恶意文件名回归，确认 React 只按文本渲染。
- 新增仅由 `?security-lab=1` 显式启用的聚合运行探针；不读取输入、存储或 URL 内容。
- `.gitignore` 补齐环境文件、日志、依赖目录、构建目录和临时目录规则。

## 4. 浏览器动态验收

在上述真实响应头下，使用纯虚构且包含以下恶意样式内容的简历文本完成主流程：HTML 图片、外部像素 URL、事件处理属性和脚本标签。

实际完成：官网进入助手、粘贴、本地事实 Worker、确认 5 条事实、产品经理方向、证据不足降级、跳过 JD、生成报告、加载公司方向数据及外链核对。

结果：

- 恶意文本只作为文本显示，`window.__xss` 未创建；
- 没有生成外部图片或内联脚本节点；
- 安全探针记录 CSP 违规 0、运行时错误 0；
- 服务器只收到同源 HTML、哈希 JS/CSS、事实提取 Worker、公司池索引和 `product-manager.json`；
- 没有请求恶意文本中的 `tracker.invalid`，也没有请求其他五个方向数据；
- 报告中的 10 个新窗口链接全部为 HTTPS、查询参数为空且包含 `noopener noreferrer`。

浏览器插件规则禁止直接读取浏览器个人存储，因此没有通过自动化工具导出 Cookie 或用户配置；存储边界继续由关闭式源码门禁、`persistencePolicy` 和清除流程测试验证。

## 5. 文件、日志与导出

- PDF.js 使用内存二进制、禁用脚本/XFA/Worker Fetch/WASM，不接收 URL；加载任务结束后销毁。
- Mammoth 只调用 `extractRawText`，不把 DOCX HTML、图片、宏、模板或外部对象插入 DOM。
- TXT 只做编码和文本规范化；10MB 上限、文件头/扩展名一致性、空文件、损坏和加密文件在重型解析前检查。
- Worker 只返回关闭式状态与错误码；页面错误不显示解析器堆栈、完整异常对象或原文片段。
- 生产应用源码无 `console.*` 用户材料日志；没有第三方埋点、远程日志或会话回放。
- 复制与打印继续使用脱敏报告生成器，不复制原始页面 DOM、文件名或临时 BYOK 密钥。
