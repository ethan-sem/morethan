## 4. 静态兼容门禁

新增构建前兼容扫描，阻止：

- `Array.prototype.toSorted`、`toReversed`、`with` 等超出首发兼容范围的新 API；
- `Promise.withResolvers`；
- 未降级的 File System Access API；
- 基于 user-agent 的 Chrome / Edge / Safari 分支；
- WebKit 私有接口。

现有代码只使用标准文件输入、Worker、Web Storage 清理、Clipboard 可用性检测和原生打印等能力；复制不可用时已有明确错误反馈，不阻断本地报告。

### 8.4 本轮兼容性修复

- 公司目标池链接最小触控高度统一为 32px；
- 输入方式标签页支持关闭式 ARIA 关联和键盘焦点切换；
- 步骤切换后焦点立即进入新页面标题；
- 清除弹窗立即获得初始焦点，并保留焦点圈定、Escape 关闭和焦点归还；
- 焦点逻辑由下一动画帧调整为提交后立即执行，避免测试环境和低帧率设备出现时序差异。

上述焦点修复属于 M7-04 的一部分基础设施；它们在 M7-03 回归中已验证，但不代表屏幕阅读器、200% 缩放和打印版等 M7-04 项已经完成。
