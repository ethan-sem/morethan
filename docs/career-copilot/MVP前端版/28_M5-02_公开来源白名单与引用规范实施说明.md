# M5-02 公开来源白名单与引用规范实施说明

> 完成日期：2026-08-13  
> 核验方式：公开网页人工核验  
> 注册表：`SourceWhitelist 1.0.0`

## 1. 交付结果

新增可执行的来源白名单契约 `src/career-copilot/domain/sourceWhitelist.js`，并发布首批静态注册表 `public/data/career-copilot/source-whitelist.json`。白名单不是普通链接收藏，而是逐项记录：

- 发布主体和来源类型；
- HTTPS 基础入口、精确允许 hostname 和主体证明页；
- 访问方式、可支持的事实类型和是否有资格证明实时状态；
- 内容使用策略、自动化策略、人工复核周期和明确限制；
- 核验日期、批准/有条件状态及排除记录。

## 2. 首批来源

### 国家公共就业来源（2）

1. 国家大学生就业服务平台：教育部文件确认其为面向高校毕业生提供职位检索、专场招聘和求职服务的综合平台。
2. 中国公共招聘网：人力资源和社会保障部公共招聘入口，提供招聘岗位、招聘会和高校毕业生就业服务。

### 高校就业来源（4）

1. 清华大学学生职业发展指导中心；
2. 北京大学学生就业指导服务中心；
3. 复旦职业发展在线；
4. 上海交通大学学生就业服务和职业发展中心。

上述页面可以提供公开招聘线索、活动信息和交叉核验，但均不能单独证明第三方企业岗位当前仍在招聘。

### 企业官方招聘来源（6）

1. 华为校园招聘；
2. 字节跳动校园招聘；
3. 京东校招；
4. 美团校园招聘；
5. 快手校招；
6. 招商银行校园招聘。

企业官方招聘源具备实时状态证据资格，但必须继续核验到具体岗位级页面。京东、快手入口因正文依赖 JavaScript 且本轮可见信息较少，标记为 `conditional`；这不影响将其作为官方入口，但在 M5-03 建立具体岗位前必须重新人工检查。

## 3. 统一引用口径

每次引用至少展示：`title`、`publisher`、`url`、`verifiedAt`。当前默认策略为：

- `usagePolicy = link_only`：只展示来源名称、链接和核验日期；
- `maxExcerptCharacters = 0`：不复制网页正文或完整 JD；
- `automationPolicy = manual_review_only`：不做浏览器端、构建端或服务端自动抓取；
- 企业来源每 7 天复核，高校和政府来源每 14 天复核；
- 岗位 `open` 必须绑定人工核验过的企业官方岗位级页面；聚合首页、搜索结果、高校转发或政府平台记录均不够；
- 不绕过登录、验证码、反爬或访问控制，不采集账号、Cookie、简历、投递状态或招聘联系人个人信息。

如果未来获得官方 API 或开放数据许可，必须新增明确的许可记录并调整单项策略，不能因为网页公开可见就自动升级为可抓取或可转载。

## 4. 暂不纳入

浙江大学就业服务平台公开页标注“未经同意，任何单位和个人不得擅自引用与转载本网站任何信息”，因此被写入 `exclusions`，在获得书面许可前不纳入白名单。

腾讯、阿里等本轮未取得与其他来源同等稳定、可公开核验的校招入口证据，暂不放入首批白名单；M5-03 若拟选择这些公司，必须先补充核验并更新白名单，不能凭品牌常识直接建档。

## 5. 验证与下一步

新增 9 项测试，覆盖静态注册表、自有 hostname 精确匹配、仿冒域名拒绝、事实授权范围、岗位级二次核验、政府/高校实时状态限制、全局人工链接策略、企业实时状态权限和明确排除项。

下一任务 M5-03 将基于本白名单制作 30 家代表性公司数据包。公司是否进入冲刺/主申/稳妥/探索不得在数据包中永久写死；具体层级仍由用户证据、岗位族和 JD 规则动态计算。
