# M4-01 版本化分析规则契约实施说明

> 完成日期：2026-08-13  
> 状态：已完成  
> 范围：规则数据结构与校验，不包含 M4-02 的实际画像计算

## 1. 完成结果

本任务建立了 `AnalysisRuleSet 1.0.0`。后续方向画像、经历证据匹配、JD 差距和行动建议可以共享同一套指标、证据、权重、阈值、解释和降级语义，而不再各自定义隐式规则。

默认规则集版本为 `2026.08.1`，仅面向实习和校招。所有结构在浏览器本地使用，不引入账号、后端、数据库、网络请求或模型密钥。

## 2. 规则组成

首版定义七类证据：个人动作、方法与工具、结果、规模、个人贡献、岗位相关性和可信度。对应七项通用指标的权重之和严格为 1：

| 指标 | 权重 |
|---|---:|
| 动作清晰度 | 0.18 |
| 方法深度 | 0.14 |
| 结果证据 | 0.20 |
| 影响规模 | 0.10 |
| 个人贡献 | 0.14 |
| 岗位相关性 | 0.16 |
| 表达可信度 | 0.08 |

每项规则包含必要/辅助证据、强/足够/弱阈值、三类结果解释、通用边界说明和降级策略。内部允许加权聚合用于排序，但契约固定 `exposeCompositeScore = false`，禁止向用户展示单一求职竞争力总分。

## 3. 证据与降级边界

- 证据引用必须存在于证据目录中；
- M4-02 及后续执行器只能从 `selectConfirmedFacts()` 的输出构造证据；
- 缺少必要证据时默认继续追问；
- 整体证据不足时默认给出条件式建议；
- 规则也可明确省略结论，但不能在证据不足时照常输出肯定判断；
- 默认置信度上限为中，不把规则分数解释为真实能力或录用概率。

## 4. 校验能力

关闭式校验覆盖：Schema 版本、未知字段、重复 ID、证据目录、悬空证据引用、权重范围及归一化、阈值范围及顺序、解释文案、降级动作、结论数量限制、复核日期和变更原因。

`assertAnalysisRuleSet()` 在结构无效时抛出稳定的 `AnalysisRuleSetError`，并附带错误码和字段路径，便于构建期规则包检查和样本回归定位。
