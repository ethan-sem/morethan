## 1. 使用规则

1. Codex 每次开发前先读取本文件及对应 MVP 规格文档。
2. 未列入本任务源的账号、服务端、数据库、运营后台、支付和服务端 AI 接口均不得自行开发。
3. 开始任务时将状态改为 `[doing]`；完成代码和验证后改为 `[done]`，并记录日期与验证证据。
4. 若实现改变范围、数据流或验收口径，先同步修改相关 MVP 文档，再修改代码。
5. 长期版任务仅保存在 `../长期开发版/README.md` 指向的冻结文档中，只有用户明确要求“恢复长期版”才能启用。

状态：`[todo]` 待开始；`[doing]` 进行中；`[review]` 待确认；`[done]` 已完成；`[blocked]` 阻塞。

## 5. 明确排除项

以下事项不属于当前任务，不得作为“顺手优化”加入：

- 注册、登录、短信/邮箱验证码、密码找回、OAuth；
- 用户中心、云端历史报告、多设备同步；
- API 服务、任务队列、数据库、对象存储；
- 在网页源码或构建变量中放置 MoreThan 的模型 API 密钥；
- 自动爬虫、实时职位聚合、运营后台；
- 付费、订阅、订单、优惠券；
- 1–3 年社招及更高年限求职场景。
