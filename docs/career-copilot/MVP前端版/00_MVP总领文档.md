# MoreThan 智能求职助手：纯前端 MVP 总领文档

> 状态：当前生效  
> 目标：尽快上线可用  
> 版本：MVP v1.0  
> 日期：2026-08-09

## 1. 一句话定义

用户在网页中本地导入简历、选择实习或校招方向后，浏览器直接完成简历结构化、证据检查、岗位匹配、公司岗位分层和行动计划生成；默认不登录、不上传、不保存。

## 2. MVP 成功标准

用户在 5–8 分钟内获得：

1. 简历中已经具备的 3 项核心证据；
2. 最值得优先修复的 3 个问题；
3. 主投与备选岗位方向；
4. 按冲刺、主申、稳健、探索划分的公司岗位池；
5. 未来 7 天的具体行动清单；
6. 可以复制或导出的本地报告。

## 3. 产品定位

MVP 是“本地求职诊断工具”，不是账号平台、招聘平台或在线陪跑系统。

它解决：

- 简历是否有清晰的动作与结果证据；
- 简历与目标 JD 的要求是否对齐；
- 当前投递组合是否过于激进或保守；
- 哪些修改最值得先做；
- 用户下一步具体做什么。

它不解决：

- 跨设备保存和长期职业档案；
- 自动抓取全网实时岗位；
- 自动投递、代答和经历伪造；
- 服务端大模型统一分析；
- 真人顾问后台；
- 录取概率与 offer 保证。

## 4. 用户范围

- 准备实习的在校生；
- 准备国内校招的应届生；
- 有 PDF、DOCX 或可粘贴文本简历；
- 目标方向为首批规则库覆盖的岗位族。

不覆盖 1–3 年社招、高管、蓝领、强执业资格和移民/签证建议。

## 5. 产品架构

```text
本地文件
  ↓ 浏览器解析，不上传
结构化经历与证据
  ↓
本地规则引擎 ← 用户粘贴的 JD
  ↓              ↑
岗位技能规则库 / 静态公司岗位库
  ↓
诊断报告 + 公司岗位分层 + 7 天行动计划
  ↓
本地复制 / 打印 / 导出
```

## 6. 核心产品原则

1. **本地优先**：简历正文默认不离开设备。
2. **真实可用**：没有大模型也能完成基础诊断，不交付纯演示页面。
3. **证据优先**：所有结论回指简历中的事实或用户选择。
4. **规则透明**：用户可以看到为什么被判为优势、缺口或某一公司层级。
5. **不伪装 AI**：规则生成的结论明确标记为“本地智能分析”；只有实际调用模型时才标记为 AI 生成。
6. **不保存密钥**：可选 BYOK 密钥只存在内存中，刷新即清除。
7. **不保证结果**：稳健层也不代表保证面试或 offer。
8. **完整免费**：所有 MVP 能力免费开放。

## 7. MVP 功能范围

### P0

- 官网一级入口；
- PDF、DOCX、TXT 和文本粘贴；
- 浏览器本地解析与格式错误提示；
- 姓名、电话、邮箱、详细住址等字段本地遮盖；
- 教育、实习、项目、校园经历、技能和成果证据识别；
- 用户事实确认与修改；
- 实习/校招、目标岗位、城市和时间采集；
- 用户粘贴 JD；
- 本地规则化优势、短板、方向和行动计划；
- 静态公司岗位知识库与四层分组；
- 证据引用、规则解释和置信度；
- 本地报告复制、打印或浏览器 PDF 导出；
- 清除本地数据；
- 移动端与 PC 基础适配。

### P1

- 可选用户自备模型密钥分析；
- 多份 JD 对比；
- 本地保存一份脱敏报告；
- 公司知识静态包的定期更新；
- 分享不含简历原文的结果摘要。

### 明确延期

- 账号与登录；
- 后端、数据库和对象存储；
- MoreThan 统一模型密钥；
- 实时岗位采集；
- 顾问后台；
- 云端报告历史；
- 跨设备同步；
- 邮件、短信和日历提醒。

## 8. 本地智能分析能力

默认规则引擎至少分析：

- 经历完整性：组织、角色、时间、动作、方法、结果；
- 结果证据：数字、规模、效率、质量、影响范围；
- 表达质量：空泛动词、重复表达、长度和可读性；
- 时间线：缺失、重叠、异常日期；
- JD 匹配：必要词、技能词、任务词和缺失证据；
- 岗位方向：首批岗位族的证据覆盖；
- 投递组合：公司岗位四层数量与风险分布；
- 行动优先级：影响、可改善性和紧迫度。

## 9. 公司与岗位数据

MVP 不实时抓取全网岗位。采用审核后的静态 JSON：

- 每条记录保留公司、岗位族、地点、招聘类型、来源 URL、核验日期和状态；
- “正在招聘”只在发布静态包时有有效官方来源时展示；
- 超过有效期自动显示“需前往官网核验”；
- 更新知识库需要重新构建并发布网站；
- 顾问维护解释和层级规则，不复制个人信息或来源不明内容。

## 10. 上线策略

第一版只追求“一条完整可用路径”：

```text
进入 → 本地导入简历 → 确认事实 → 选择方向 → 粘贴 JD
→ 本地分析 → 查看报告 → 导出 → 清除
```

不先建设多用户、实时同步或运营后台。首版通过官网静态部署上线，不增加持续服务器运维。

## 11. 进入长远版的触发条件

满足任一条件时，再由用户明确要求启用长远开发版：

- 需要 MoreThan 统一提供大模型分析；
- 需要跨设备保存或长期档案；
- 需要账号、顾问协作或人工复核；
- 需要实时招聘数据；
- 需要收集投递反馈和长期行动；
- 日活规模证明本地 MVP 有持续价值。
