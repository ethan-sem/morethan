# 全量自查缺陷修复与回归记录

日期：2026-08-20  
范围：MoreThan 智能求职助手纯前端 MVP  
结论：本地发现的功能、路由、会话状态、时效降级和证据断链缺陷已修复；外部浏览器/实机、读屏、真实打印、内容顾问和管理层签字仍属于 M7-07 发布阻断。

## 1. 已关闭缺陷

1. 补齐 `MFR-031`：支持一个主投方向和最多两个备选方向，主备方向互斥。
2. 补齐 `MFR-032`：目标城市可多选，开始投递时间可选，并可填写硬约束。
3. 补齐 `MFR-050`：公司推荐输出显式包含行业、公司、岗位族、目标地点上下文和招聘类型；地点没有公开岗位级证据时明确标记为需在官方岗位页核验，不虚构城市覆盖。
4. 补齐 `MFR-055`：用户可按公司、城市和行业设置排除条件；公司与行业在本地过滤，城市同时从目标地点上下文剔除，报告显示已应用的过滤边界。
5. 非法或过时 Hash 统一回退首页，不再出现只剩导航的空白页。
6. 助手存在未导出内存态资料时，顶部导航、助手退出和浏览器前进/后退均经过同一离开确认；取消离开不会卸载助手。
7. 行动勾选状态提升到助手会话级内存，从数据设置返回后继续保留；一键清除、材料/JD/分析变化时仍会失效。
8. 打印不再直接标记为“已成功导出”；只有成功复制脱敏文本后才关闭未导出提醒，避免用户取消打印后失去保护。
9. M7-07 证据清单中的 M7-03 文件名已修正为实际存在的“浏览器与移动端兼容验证记录”。
10. 外部数据过期不再导致纯前端站点无法构建：Schema、来源白名单、数量和引用错误继续阻断；时效到期改为构建警告，运行时强制显示“待自行核实”。没有伪造或顺延任何核验日期。
